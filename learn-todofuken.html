都道府県とは何か？なぜ47つあるのか

都道府県は、日本全国を区分した行政単位です。現在の47都道府県は「1都・1道・2府・43県」で構成されています。

  • 「都」：東京都の1つだけ
  • 「道」：北海道の1つだけ
  • 「府」：大阪府・京都府の2つ
  • 「県」：残りの43県

ポイント：都・道・府・県は名前が違うだけで、行政上の権限や仕組みはほぼ同じです。

なぜ47つなのか？廃藩置県の歴史

明治時代以前の日本には、藩主（大名）が治める「藩」が300以上存在していました。1871年（明治4年）、明治政府は「廃藩置県」を断行し、全国の藩を廃止して府県に統合しました。当初は3府302県もありましたが、その後合併・再編を繰り返し、1888年頃に現在の47の形にほぼ落ち着きました。

つまり「47」という数字は歴史的な経緯の産物で、特別な意味があるわけではありません。

地方区分の覚え方

47都道府県は8つの地方に分類されています。地方ごとにまとめて覚えると効率的です。

北海道地方（1）

北海道のみ。日本最大の面積を持つ都道府県です。

東北地方（6県）

  • 青森県・岩手県・宮城県・秋田県・山形県・福島県

覚え方：「あ（青森）い（岩手）みや（宮城）あき（秋田）やま（山形）ふく（福島）」

関東地方（7都県）

  • 茨城県・栃木県・群馬県・埼玉県・千葉県・東京都・神奈川県

中部地方（9県）

  • 新潟県・富山県・石川県・福井県・山梨県・長野県・岐阜県・静岡県・愛知県

近畿地方（7府県）

  • 三重県・滋賀県・京都府・大阪府・兵庫県・奈良県・和歌山県

中国地方（5県）

  • 鳥取県・島根県・岡山県・広島県・山口県

四国地方（4県）

九州・沖縄地方（8県）

県庁所在地が県名と違う都道府県

多くの県は「○○県○○市」のように県名と一致しますが、一部は異なります。テストで頻出のものをまとめました。

  • 北海道　→　札幌市
  • 岩手県　→　盛岡市
  • 宮城県　→　仙台市
  • 群馬県　→　前橋市
  • 栃木県　→　宇都宮市
  • 埼玉県　→　さいたま市
  • 神奈川県　→　横浜市
  • 石川県　→　金沢市
  • 愛知県　→　名古屋市
  • 兵庫県　→　神戸市
  • 島根県　→　松江市
  • 香川県　→　高松市
  • 愛媛県　→　松山市
  • 沖縄県　→　那覇市

暗記のコツ：「県名≠県庁所在地」の県を集中して覚えましょう。一致している県は自然と覚えられます。

よくある間違い・テストで差がつくポイント

❌ 島根県と鳥取県を逆に覚えてしまう

「鳥取は東、島根は西」と覚えましょう。東京から見て先に通るのが鳥取県です。「と（東）っ（鳥取）て（取って）し（島根）まう（西）」という語呂合わせも有効です。

❌ 群馬県と栃木県を逆に覚えてしまう

関東地方の北側に並ぶこの2県、「群馬は西、栃木は東」です。群馬（ぐんま）は埼玉の北西、栃木（とちぎ）は茨城の左隣です。

❌ 「県庁所在地＝一番大きな市」とは限らない

たとえば三重県の県庁所在地は津市ですが、人口は四日市市のほうが多いです。県庁所在地は歴史的な経緯で決まることが多く、人口規模とは別の話です。
