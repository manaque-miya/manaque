相加相乗平均とは何か

a, b ≧ 0 のとき (a+b)/2 ≧ √(ab) が成り立つ——これが相加相乗平均の不等式だ。左辺が「相加平均（算術平均）」、右辺が「相乗平均（幾何平均）」で、算術平均は幾何平均以上になるという事実を表している。

変形すると a + b ≧ 2√(ab)（よく使う形）。等号成立は a = b のとき（等号 = ⟺ a = b）。「a, b ≧ 0 の確認」と「等号成立条件の明示」が記述答案の必須要素だ。

基本公式と証明

公式条件
(a+b)/2 ≧ √(ab)a, b ≧ 0（等号成立 ⟺ a = b）
a + b ≧ 2√(ab)a, b ≧ 0（等号成立 ⟺ a = b）

証明（差を取る方法）

a + b − 2√(ab) = (√a − √b)² ≧ 0
(√a − √b)² = a − 2√(ab) + b だから a + b ≧ 2√(ab) が成り立つ。
等号成立は √a = √b、すなわち a = b のとき（a, b ≧ 0 を前提）。

例題①：a + 1/a の最小値（a > 0）

相加相乗平均より a > 0、1/a > 0 に対して：

a + 1/a ≧ 2√(a × 1/a) = 2√1 = 2

等号成立は a = 1/a → a² = 1 → a = 1（a > 0 より）

よって a + 1/a の最小値は 2（a = 1 のとき）

例題②：a² + b² ≧ 2ab の証明

a² と b² に相加相乗平均を適用（a², b² ≧ 0）：
a² + b² ≧ 2√(a²b²) = 2|ab| ≧ 2ab
（|ab| ≧ ab は常に成立）

適用条件チェックリスト

  • a, b ≧ 0 の確認——負の数には直接使えない（問題文の条件を必ず確認）
  • 等号成立条件の明示——「a = b のとき等号成立」を答案に必ず書く
  • 和が一定か積が一定かを判断——積 ab = k（一定）なら和 a + b の最小値、和 a + b = k（一定）なら積 ab の最大値を求める問題
  • 最小値に達することの確認——等号成立条件が与えられた制約（a > 0 など）と矛盾しないか確認する

2パターンの頻出問題

パターン問題の形使い方
積が一定 → 和の最小ab = k のとき a + b の最小値a + b ≧ 2√(ab) = 2√k
和が一定 → 積の最大a + b = k のとき ab の最大値ab ≦ ((a+b)/2)² = (k/2)²

3変数への拡張

a, b, c ≧ 0 のとき (a+b+c)/3 ≧ ³√(abc)（3変数の相加相乗平均）
等号成立 ⟺ a = b = c
「a + b + c の最小値（abc = k 固定）」や「abc の最大値（a + b + c = k 固定）」で使う。

試験のキモ

  • a + b ≧ 2√(ab)——等号成立は a = b のとき（a, b ≧ 0）
  • a + 1/a の最小値は 2（a = 1 のとき）——最頻出パターン
  • 「積が一定 → 和の最小」「和が一定 → 積の最大」の2パターンを使い分ける
  • 記述式では「a, b ≧ 0 より相加相乗平均を適用すると…、等号成立は a = b のとき」という論理を明示する
  • 最多のミスは「等号成立条件を書かない」こと——条件を省くと記述式では減点される

試験対策・まとめ

数学検定2級〜準1級の不等式分野では相加相乗平均が頻出だ。「a + 1/a の最小値」「ab が一定のとき a + b の最小値」という2パターンは必ず出る問題型なので手順を完全に自動化しておくことが独学対策の基本だ。記述式では「a, b ≧ 0 を確認 → 相加相乗平均を適用 → 等号成立条件を明示 → 最小値（または最大値）を結論づける」という4ステップの論理展開を丁寧に書くことが満点答案の条件だ。3変数への拡張（(a+b+c)/3 ≧ ³√(abc)）も準1級では出題されるため、公式と等号成立条件（a = b = c）をセットで覚えておくことが重要だ。
