ベクトルの垂直条件とは何か

2つのベクトルが直角（90°）をなすための必要十分条件が「内積 ＝ 0」だ。a→・b→ ＝ 0 ⟺ a→ ⊥ b→（零ベクトルを除く）というシンプルな式が、直角かどうかを判定する最強のツールだ。

💡 ポイント: なぜ内積 ＝ 0 で垂直になるのか。内積の定義 a→・b→ ＝ |a→||b→|cosθ で、θ ＝ 90° なら cos90° ＝ 0 だから内積 ＝ 0 になる。逆に内積 ＝ 0（かつ零ベクトルでない）なら cosθ ＝ 0 → θ ＝ 90° が導かれる。

垂直条件の使い方

例題1（判定）: a→ ＝ (1, 2) と b→ ＝ (4, −2) は垂直か？

a→・b→ ＝ 1×4 ＋ 2×(−2) ＝ 4 − 4 ＝ 0

→ 内積 ＝ 0 なので 垂直（直交）

例題2（未知数を求める）: a→ ＝ (3, k) と b→ ＝ (2, 3) が垂直になるとき k を求めよ。
ステップ式結果
① 垂直条件を立てるa→・b→ ＝ 03×2 ＋ k×3 ＝ 0
② 計算6 ＋ 3k ＝ 03k ＝ −6
③ 解くk ＝ −2k ＝ −2
内積の正負による角度の判定:
内積の値なす角 θ関係
a→・b→ ＞ 00° ＜ θ ＜ 90°鋭角
a→・b→ ＝ 0θ ＝ 90°直交（垂直）
a→・b→ ＜ 090° ＜ θ ＜ 180°鈍角
⚠️ 間違いやすいパターン: 「大きさが同じなら垂直」という誤解がある——垂直は大きさと無関係だ。また「零ベクトルとの内積は常に0」だが、零ベクトルは垂直・平行の概念から除外される点に注意。さらに内積 ＜ 0 を「垂直に近い」と解釈するのも誤り——鈍角をなすということだ。

ここが試験のキモ ✅

✅ 垂直⟺内積 ＝ 0（零ベクトルを除く）——最重要条件
✅ 未知数が含まれるとき「内積 ＝ 0」の方程式を立てて解く
✅ 内積の正負で鋭角・直角・鈍角の3段階が判定できる

平行条件との比較

条件内積成分での言い換え
垂直（直交）a→・b→ ＝ 0a₁b₁ ＋ a₂b₂ ＝ 0
平行a→ ＝ ka→（実数倍）a₁:a₂ ＝ b₁:b₂
垂直は「内積 ＝ 0」で判定できるが、平行は「成分の比が等しい（または一方が他方の実数倍）」で判定する——判定方法が全く異なる。

🎯 試験対策：垂直条件の重要ポイント

数学検定2級の1次では「垂直になる条件を求めよ」という問題が定番だ。「a→・b→ ＝ 0 を立式 → 成分代入 → k について解く」という3ステップを繰り返し練習することで確実に得点できる問題になる。

2次（記述式）では「三角形 ABC の角 B が直角であることを証明せよ」というような問題が出る。この場合は「BA→・BC→ ＝ 0 を示す」という方針で立式し、各ベクトルを位置ベクトルで表してから成分計算で内積を求めるという手順が標準解法だ。証明問題では「内積が0になること＝角Bが直角」という結論の根拠を明示して答案を締めくくること。
