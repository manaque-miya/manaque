グラフの平行移動とは何か

中村さん（中学3年生・数学検定3級受験）が「x 方向に ＋3 なのに (x＋3) じゃないの？」と混乱していた。先生が「移動後の x ＝ 3 に元の x ＝ 0 の値を対応させたいから (x−3) なんだよ」と説明すると、中村さんは「逆に入れるんだ」と納得した表情を見せた。

y ＝ f(x) のグラフを x 方向に p、y 方向に q 平行移動したグラフの方程式は y ＝ f(x − p) ＋ q になる。x 方向の移動量 p は「マイナス符号で x に入る」という符号の反転が最大の落とし穴だ。y 方向は「q をそのままプラス」するだけで符号は変わらない。この非対称性を理解することが平行移動マスターの核心だ。

💡 ポイント: なぜ x 方向への移動で符号が反転するのか。「x 方向に p だけ移動する」とは、「元の関数で x ＝ 0 に対応していた点が、移動後には x ＝ p に移る」ことを意味する。移動後のグラフで x ＝ p を代入したとき元の f(0) の値が出てほしいから f(p − p) ＝ f(0) になるよう「x − p」が必要だ。つまり x を x − p に置き換えることで「p 右にシフト」が実現する。

平行移動の公式と例

基本公式:

y ＝ f(x) を x 方向に p、y 方向に q 移動 → y ＝ f(x − p) ＋ q

移動の種類元の関数移動後ポイント
x 方向に ＋3y ＝ x²y ＝ (x − 3)²x に −3（符号反転！）
x 方向に −2y ＝ x²y ＝ (x ＋ 2)²x に ＋2（逆符号）
y 方向に ＋4y ＝ x²y ＝ x² ＋ 4そのまま ＋4
x に ＋1、y に −3y ＝ sin xy ＝ sin(x − 1) − 3組み合わせ

例題: y ＝ x² − 2x ＋ 1 ＝ (x − 1)² を x 方向に 3、y 方向に −2 移動せよ。

解: x を x − 3 に置き換え、さらに y 方向に −2 する。

y ＝ (x − 3 − 1)² − 2 ＝ (x − 4)² − 2

（頂点が (1, 0) から (4, −2) に移動した二次関数）

二次関数の頂点形との対応:

y ＝ a(x − p)² ＋ q は「y ＝ ax² を x 方向に p、y 方向に q 移動した関数」と解釈できる——これが頂点形の幾何的な意味だ。

⚠️ 間違いやすいパターン: 最も多いミスは「x 方向に ＋3 移動するから (x ＋ 3) に変える」というものだ。正しくは (x − 3) だ。この符号反転は「関数の引数の変換」と「グラフの移動方向」の間にある逆の関係から来る——引数を 3 増やすと x の値を 3 小さくした点を見ているため、グラフは右（正方向）に移動する。もう一つのミスは「y 方向の移動で符号も反転させる」こと——y 方向は f(x) に q を足すだけで符号は変わらない。「x だけ逆符号、y はそのまま」というルールを徹底すること。

ここが試験のキモ ✅

  • ✅ y ＝ f(x − p) ＋ q が「x 方向に p、y 方向に q 移動」の公式
  • ✅ x 方向の移動は符号が反転——「右 p 移動 → x − p に置き換え」
  • ✅ y 方向の移動は符号そのまま——「上 q 移動 → ＋q を加える」

複合移動と注意点

複数の変換（平行移動・対称移動・拡大縮小）が組み合わさる問題では、変換の順序が重要だ。「x を ax ＋ b に置き換える」形の変換は「平行移動と拡大縮小の組み合わせ」になる——このとき平行移動量は変換後の係数に依存することに注意する。

🎯 試験対策：グラフの平行移動の重要ポイント

数学検定2級〜準1級では「次の関数のグラフを描け」「移動した関数の方程式を求めよ」という問題が定番だ。「二次関数の頂点形の読み取り」「三角関数の位相シフト」「絶対値関数の頂点移動」など、幅広い関数で同じ原理が使われる。

数学検定 過去問・勉強方法・独学での最善策は「頂点形 y ＝ a(x − p)² ＋ q の頂点が (p, q) になる理由を平行移動の観点から説明できる」レベルまで理解を深めることだ。記述式では「なぜこの式になるか」の論拠を答案に書く機会があるため、公式の丸暗記より仕組みの理解が高得点に直結する。
