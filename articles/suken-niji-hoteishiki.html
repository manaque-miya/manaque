二次方程式方程式・不等式数学検定

二次方程式とは何か

「x²（xの2乗）の項を含む方程式」が二次方程式だ。ax²＋bx＋c＝0（a≠0）の標準形を持ち、実数の範囲で解が最大2つ存在する（判別式によって0個・1個・2個が決まる）。中学3年で導入されるが、高校数学の基礎体力として数学検定のあらゆる問題で使われる。

💡 ポイント: 二次方程式の解法は3種類——①因数分解、②平方完成（x＝±√k 形式に変形）、③解の公式。どれを使うかは式の形によって判断し、迷ったら解の公式が確実。

3つの解法の使い分け

解法①：因数分解（整数解が見込める場合）

x²－5x＋6＝0 → (x－2)(x－3)＝0 → x＝2 または x＝3

解法②：平方完成（左辺を (x－p)²＝k の形に変形）

x²＋4x－1＝0
→ (x＋2)²－4－1＝0
→ (x＋2)²＝5
→ x＝－2±√5

解法③：解の公式（すべての二次方程式に適用可能）

ax²＋bx＋c＝0 のとき x＝(－b±√(b²－4ac))/(2a)

解法向いている場面計算量
因数分解整数解・「足して○掛けて○」が見える場合少ない
平方完成二次関数の頂点求めにも使う場合中程度
解の公式どんな形にも対応、確実やや多い
⚠️ 間違いやすいパターン: 解の公式で「－b」の符号ミス（b の符号をそのまま使ってしまう）と「分母が 2a（a ではなく 2a）」の取り違えが最頻出。a, b, c を確認してから解の公式に代入する習慣をつけること。

ここが試験のキモ ✅

✅ まず因数分解を試みる——整数のペアがすぐ見つからなければ解の公式へ
✅ 解の公式 x＝(－b±√(b²－4ac))/(2a) を正確に暗記する
✅ 「解が1つ（重解）」は判別式 D＝0 のとき——x＝－b/(2a) が唯一の解

二次方程式と文章題

問題のタイプ方程式の立て方
面積の問題縦×横＝面積 でx を含む式を立てる
整数の問題連続する整数を n, n＋1, n＋2 で表す
速さの問題距離＝速さ×時間 を変形して立式

🎯 試験対策：二次方程式の重要ポイント

数学検定3級・準2級の1次では「係数が整数の二次方程式を解く」問題が定番だ。因数分解できるかを素早く判断するには「x² ＋bx＋c で b と c の符号パターン（両方正なら両方正の組み合わせ、c が負なら符号が逆の組み合わせ）」を型として覚えておくと判断が速くなる。

2次（記述式）では「二次方程式を利用した文章題」が頻出だ。問題文の条件を「等しい量」に着目してx で表し、方程式を立ててから解く流れを丁寧に書く。答えが2つ出た場合は「問題の文脈に合わない方を棄却する（例：長さなのでマイナスは不適）」という理由付けを必ず記述すること。
