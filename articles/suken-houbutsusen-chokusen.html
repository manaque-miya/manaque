放物線と直線の交点とは何か

二次関数（放物線）と一次関数（直線）の交点の座標、または交点の個数を求める問題が「放物線と直線の交点」だ。解法の核心は「2つの関数の y を等置する」ことでx だけの二次方程式を作り、その解が交点の x 座標になることだ。グラフを使わずに代数的に正確に求めることが数学検定では要求される。

💡 ポイント: 放物線 y ＝ ax² ＋ bx ＋ c と直線 y ＝ mx ＋ n の交点を求めるには、y を等置して ax² ＋ bx ＋ c ＝ mx ＋ n、整理して ax² ＋ (b − m)x ＋ (c − n) ＝ 0 という x だけの二次方程式を作る。この方程式の判別式 D で交点の個数を判断し、解を求めることで交点の x 座標が得られる——直線の式に代入すれば y 座標も求まる。

解法手順と例

放物線と直線の交点を求める4ステップ:

ステップ操作目的
① y を等置ax² ＋ bx ＋ c ＝ mx ＋ nx だけの式にする
② 整理ax² ＋ (b − m)x ＋ (c − n) ＝ 0二次方程式の標準形
③ 判別式で個数確認D ＝ (b−m)² − 4a(c−n)2交点 / 接線 / 交わらない
④ 解を求める因数分解 or 解の公式交点の x 座標 → y 座標

例題: y ＝ x² と y ＝ 2x ＋ 3 の交点を求めよ。

①②: x² ＝ 2x ＋ 3 → x² − 2x − 3 ＝ 0

③ D ＝ 4 ＋ 12 ＝ 16 ＞ 0（2点で交わる）

④ (x − 3)(x ＋ 1) ＝ 0 → x ＝ 3 または x ＝ −1

x ＝ 3 のとき y ＝ 9、x ＝ −1 のとき y ＝ 1

→ 交点：(3, 9) と (−1, 1)

直線が放物線に接する場合（D ＝ 0）:

y ＝ x² と y ＝ kx が接する（1点で交わる）条件：

x² ＝ kx → x² − kx ＝ 0 → D ＝ k² ＝ 0 → k ＝ 0

（k ＝ 0 のときのみ接する——この場合は x 軸が接線）

⚠️ 間違いやすいパターン: 最もよくある計算ミスは「y を等置した後に移項を間違えて符号が逆になる」ことだ。ax² ＋ bx ＋ c ＝ mx ＋ n を整理するとき、右辺を全て左辺に移すと ax² ＋ (b − m)x ＋ (c − n) ＝ 0——各係数の符号を丁寧に処理することが必要だ。次のミスは「交点の x 座標を求めた後、y 座標を放物線と直線どちらに代入しても同じ」という確認を省略してy 座標を誤るケース——どちらに代入しても交点なので同じ値になるはずだが、計算ミスがあれば結果が違う。検算として両方に代入して確認する習慣が有効だ。

ここが試験のキモ ✅

  • ✅ 放物線と直線の交点は「y を等値して x だけの二次方程式」→ 解が x 座標
  • ✅ 判別式 D で交点数を先に確認してから解を求める
  • ✅ x 座標が求まったら直線（または放物線）に代入して y 座標を計算

放物線と直線が囲む面積

放物線と直線が2点で交わる場合、囲まれた面積は |a|/6 × (β − α)³ という公式で求められる（a は放物線の x² の係数、α と β は交点の x 座標）。この「1/6 公式」は数学検定2級〜準1級の積分分野でも出てくるため、放物線と直線の交点と一緒に覚えておくことで学習効率が上がる。

🎯 試験対策：放物線と直線の交点の重要ポイント

数学検定2級では放物線と直線の交点問題が単独で出題され、準1級では「交点の座標 → 囲まれる面積」という複合問題が頻出だ。数学検定 過去問・勉強方法・独学で「y を等値して二次方程式を作る」手順を自動化するまで反復することが最善の対策だ。

特に「直線の式に文字定数 k が含まれる」問題（「y ＝ kx ＋ 1 が y ＝ x² − x に接する条件を求めよ」など）では D ＝ 0 の条件を立式してから k を求める手順が必要になる——「接する ＝ D ＝ 0」という変換を瞬時に行える練習をしておくことが重要だ。
