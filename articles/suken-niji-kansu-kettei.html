二次関数の決定とは何か

「グラフが特定の条件を満たすような二次関数の式を求める」問題が二次関数の決定だ。y ＝ ax² ＋ bx ＋ c という標準形には未知数が a, b, c の3つあるため、3つの独立な条件が揃って初めて式が一意に決まる。与えられる条件の種類によって「標準形で連立方程式を立てるか」「頂点形を使うか」の解法を使い分けることが合否を分ける判断力だ。

💡 ポイント: 二次関数の決定では「条件の種類」によって使う標準形を変えると効率的だ。①3点が与えられる → 標準形 y ＝ ax² ＋ bx ＋ c で連立方程式、②頂点と1点が与えられる → 頂点形 y ＝ a(x − p)² ＋ q を使う、③対称軸と2点が与えられる → 対称軸 x ＝ p から a(x − p)² ＋ q の形で、④x 切片（軸との交点）2点と別の1点 → 因数形 y ＝ a(x − α)(x − β) を使うと計算が最短になる。

条件別の解法パターン

パターン別の解法まとめ:

与えられる条件使う標準形設定する未知数方程式の本数
3点を通るy ＝ ax² ＋ bx ＋ ca, b, c3本
頂点(p, q)と1点y ＝ a(x − p)² ＋ qa のみ1本
x 軸との交点 2点(α, 0)(β, 0)と1点y ＝ a(x − α)(x − β)a のみ1本
軸 x ＝ p と2点y ＝ a(x − p)² ＋ qa, q2本

例題①（3点）: (0, 1), (1, 4), (−1, 0) を通る二次関数を求めよ。

y ＝ ax² ＋ bx ＋ c に代入：

  • x ＝ 0: c ＝ 1
  • x ＝ 1: a ＋ b ＋ 1 ＝ 4 → a ＋ b ＝ 3
  • x ＝ −1: a − b ＋ 1 ＝ 0 → a − b ＝ −1

連立して a ＝ 1, b ＝ 2, c ＝ 1 → y ＝ x² ＋ 2x ＋ 1

例題②（頂点＋1点）: 頂点が (2, −3) で点 (0, 1) を通る二次関数を求めよ。

y ＝ a(x − 2)² − 3 に (0, 1) を代入：

1 ＝ 4a − 3 → a ＝ 1 → y ＝ (x − 2)² − 3 ＝ x² − 4x ＋ 1

⚠️ 間違いやすいパターン: 「頂点形 y ＝ a(x − p)² ＋ q にも実は a, p, q の3未知数がある」という事実を見落とすのが典型ミスだ。「頂点がわかれば p と q が決まり、残り1点で a が決まる」——つまり「頂点＋1点」で合計3条件が揃っている。また「x 切片 2点」の条件では「y ＝ a(x − α)(x − β)」の因数形を使うと a 以外の未知数が消えて計算が格段に楽になる——この形を知らずに標準形で連立する受験生が多い。問題の条件を見てから「最適な形」を選ぶ習慣が効率的な解法の鍵だ。

ここが試験のキモ ✅

  • ✅ 二次関数の決定には3条件が必要——a, b, c（または a, p, q）の3未知数を決める
  • ✅ 「頂点と1点」→頂点形、「x 切片2点と1点」→因数形が最速
  • ✅ 「3点通る」→標準形で連立方程式——計算量が最多だが確実な手法

「最大値・最小値が与えられる場合」の注意

「最大値が 5 で x ＝ 1 のとき最大値をとる」という条件が与えられると、「頂点が (1, 5) かつ上に凸（a ＜ 0）」という2条件が出る。この場合は y ＝ a(x − 1)² ＋ 5（a ＜ 0）という頂点形で式を立て、別の1点（または x 切片などの追加条件）で a を決定する。「最大値の条件は頂点の y 座標の条件である」という認識が必要だ。

🎯 試験対策：二次関数の決定の重要ポイント

数学検定準1級の2次（記述式）では「条件を満たす二次関数を求めよ」という問題が頻出だ。数学検定 過去問・勉強方法・独学で得点を最大化するには「条件の種類を分類して最短の解法形式を選ぶ」判断を最初の5秒で行う訓練が必要だ。過去問では「頂点形で立式→1点代入→a を求める」パターンが高頻度で出るため、このルーティンを確実にできるよう繰り返し練習することが最善の独学対策だ。
