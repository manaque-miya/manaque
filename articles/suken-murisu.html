無理数数と式（中学）数学検定

無理数とは何か

「分数の形では絶対に表せない数」が無理数だ。小数で書くと無限に続いて循環しない（無限非循環小数）。代表的なものは √2＝1.41421356…、√3＝1.73205080…、π（円周率）＝3.14159265…、e（ネイピア数）＝2.71828…などだ。数学検定では「無理数であることの証明」が2次の記述問題として出題されることもある。

💡 ポイント: 無理数の特徴は「無限に続く小数で、どこかから繰り返す規則性がない（非循環）」こと。循環小数は分数に直せるから有理数——この区別が重要。

無理数の判別

数分類理由
√2無理数1.414…と循環しない
√4有理数（整数2）√4＝2 と整数になる
√(4/9)有理数（2/3）√(4/9)＝2/3 と分数になる
π無理数分数で表せない超越数
log₂ 3無理数2^x＝3 を満たす x は分数にならない
√が無理数になる条件：√a が無理数 ⟺ a が完全平方数（1, 4, 9, 16, 25…）でない
⚠️ 間違いやすいパターン: 「0.33333…（循環小数）は無限に続くから無理数」という誤解が非常に多い。0.333…＝1/3 と分数で表せるので有理数。「無限小数＝無理数」ではない——「無限に続いて規則性がない（非循環）」場合だけが無理数。

ここが試験のキモ ✅

✅ 無理数＝「分数で表せない、無限非循環小数」
✅ 循環小数（0.333…など）は有理数——無理数ではない
✅ √が完全平方数の√なら有理数（√16＝4）、そうでなければ無理数（√5）

√2 が無理数であることの証明（背理法）

√2 が有理数だと仮定すると、p/q（既約分数）と書けるはず。
→ 2＝p²/q² → p²＝2q² → p は偶数 → p＝2m と置くと
→ 4m²＝2q² → q²＝2m² → q も偶数
→ p と q がともに偶数は「既約分数」に矛盾 → √2 は無理数

🎯 試験対策：無理数の重要ポイント

数学検定2級〜準1級では「√2 が無理数であることを背理法で証明せよ」という問題が出る。証明の流れは①「√2 が有理数（既約分数 p/q）と仮定する」②「両辺を2乗して p²＝2q²」③「p が偶数であることを示す」④「q も偶数になって既約分数に矛盾」の4ステップ。

この証明は背理法の基本パターンとして頻出なので、流れを丸ごと書けるように練習しておくこと。また「有理数・無理数・実数の関係」を問う知識問題は検定3級でも出るため、分類の定義（有理数＝分数で表せる、無理数＝表せない）を明確に押さえること。
