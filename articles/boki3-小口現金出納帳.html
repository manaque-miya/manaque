小口現金出納帳とは何か

小口現金出納帳（こぐちげんきんすいとうちょう）とは、小口現金の受入・払出を日付順に詳細記録する補助記入帳だ。「小口現金出納帳 とは」「小口現金出納帳 書き方」と検索されるほど、簿記3級 試験の第2問で定番の帳簿記入問題として出題される。

日常の少額支払を担当する用度係（担当者）が、タクシー代・切手代・文具代などの支払いをその都度このノートに記録する。科目別の内訳欄があるため、月末や週末に集計するだけで「通信費いくら・交通費いくら」が一目で分かる。総勘定元帳の小口現金勘定よりも詳細で、実務の現場感がある帳簿だ。

小口現金出納帳の構造と記入方法

小口現金出納帳の典型的な帳簿フォーマットは以下の通りだ。

日付 │ 摘要               │ 受入    │ 支出合計 │ 通信費  │ 交通費  │ 消耗品費 │ 残高
─────┼───────────────────┼─────────┼──────────┼─────────┼─────────┼──────────┼───────
4/1  │ 前渡し             │ 100,000 │         │         │         │          │ 100,000
4/5  │ 切手代             │         │   1,200  │   1,200 │         │          │  98,800
4/8  │ タクシー代         │         │   2,500  │         │   2,500 │          │  96,300
4/12 │ コピー用紙代       │         │   3,000  │         │         │    3,000 │  93,300

4/30 │ 当月補給           │   6,700 │          │         │         │          │ 100,000
記入のポイント：
  1. 受入欄：月初の前渡し額・月末の補給額を記入する
  2. 支出欄：支払った金額の合計と科目別内訳を記入する
  3. 残高欄：受入 − 支出の累計。定額資金前渡法では補給後に前渡し額に戻る

    旅費交通費 2,500円
    消耗品費  3,000円 ／ 貸方：当座預金 6,700円
（報告と補給が同時に行われる一括補給の場合）

試験のキモ

簿記3級 過去問の第2問では、小口現金出納帳の記入問題が定番で出題される。

  1. 科目別内訳欄への正確な振り分け：通信費・旅費交通費・消耗品費など、問題文の費目を正確に欄に書く
  2. 残高欄の計算：前残高 ＋ 受入 − 支出 ＝ 次の残高（日付ごとに更新）
  3. 月末合計行の記入：受入合計・支出合計・科目別合計・月末残高をそれぞれ集計
  4. 補給後の残高確認：定額資金前渡法では補給後に前渡し額と一致するはず（チェック可能）
最も多い失点ポイントは「科目の分類誤り」と「残高の累計計算ミス」だ。試験では一行ずつ残高を計算しながら進めると確実だ。

混同しやすい用語

帳簿記録対象目的
小口現金出納帳小口現金の受入・払出用度係の少額支払を費目別管理
現金出納帳会社全体の現金収支現金の全入出金を時系列記録
当座預金出納帳当座預金の入出金小切手振出・入金を記録
  • 小口現金出納帳 vs 現金出納帳：小口は用度係が管理する少額現金専用、現金出納帳は会社全体の現金
  • 小口現金出納帳 vs 総勘定元帳の小口現金勘定：出納帳は費目別の詳細記録、元帳は勘定別の金額合計

試験対策・関連リンク

簿記3級 仕訳 覚え方として「小口現金出納帳の残高は常に前渡し額に収束する」点を軸に理解すると全体像がつかみやすい。簿記3級 独学では、実際に出納帳のフォーマットを手書きで何度か埋める練習が最も効果的だ。簿記3級 過去問の第2問に出る「小口現金出納帳の月末残高を求めよ」型では、受入・支出を一行ずつ追いながら残高欄を埋めていくことで得点できる。定額資金前渡法（インプレストシステム）とセットで理解すると、補給のタイミングと金額の理由が自然に分かる。
