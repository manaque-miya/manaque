高次方程式とは何か

3次以上の多項式方程式を高次方程式という。高校数学では「因数定理を使って1つの解を見つけ、組立除法で次数を下げる」という解法が標準だ。「整数解の候補は定数項の約数」という探索法と組み合わせることで、多くの3次・4次方程式を系統的に解くことができる。

因数定理の核心——「P(a) = 0 ならば (x − a) が P(x) の因数」。まず「整数解の候補 = 定数項の約数（符号含む）」をリストアップし、P(a) を計算して 0 になる a を見つける。

解法の4ステップ（例：x³ − 6x² + 11x − 6 = 0）

① 整数解の候補：定数項 ±6 の約数 → ±1, ±2, ±3, ±6

② 候補を代入：P(1) = 1 − 6 + 11 − 6 = 0 ✓ → x = 1 が解

③ 組立除法（(x − 1) で割る）：

1−611−6
↓1−56
商1−560（余りなし）

→ x³ − 6x² + 11x − 6 = (x − 1)(x² − 5x + 6)

④ 二次因数を因数分解：x² − 5x + 6 = (x − 2)(x − 3)

→ 解：x = 1, 2, 3

剰余定理・因数定理の対比

定理内容使い方
剰余定理P(x) を (x − a) で割った余りは P(a)余りを求めるとき
因数定理P(a) = 0 ⟺ (x − a) が P(x) の因数因数分解・解を求めるとき

因数定理は「剰余定理の特殊ケース（余りが0のとき）」と理解すると整理しやすい。

特殊な高次方程式

  • 複二次式（x⁴ に x² の項のみ）：t = x² と置換して二次方程式に帰着
  • 相反方程式（係数が前後対称）：x + 1/x = t と置換
  • 因数分解できる形：グループ化して共通因数を括り出す

試験のキモ

  • 高次方程式の標準解法：「因数定理で1解 → 組立除法で次数下げ → 繰り返し」
  • 整数解の候補は「定数項の約数 ÷ 最高次の係数の約数」
  • 剰余定理（余り = P(a)）と因数定理（P(a) = 0 ⟺ 因数）の違いを明確に
  • 記述式では「x = 1 を代入すると P(1) = 0 より x = 1 は解であり、(x − 1) が因数」という論理展開を丁寧に記述する
