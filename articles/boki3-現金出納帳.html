現金出納帳とは何か

現金出納帳（げんきんすいとうちょう）とは、現金の受入（入金）と払出（出金）を日付順に詳細記録する補助記入帳だ。「現金出納帳 とは」「現金出納帳 書き方」と検索されるほど、簿記3級 試験の第2問で帳簿記入問題として頻出の論点だ。

家計簿に近いイメージで、いつ・何のために・いくら入って・いくら出て・残高はいくらか、をすべて時系列で記録する。総勘定元帳の現金勘定が科目別の金額集計なのに対し、現金出納帳は「なぜ動いたか」（摘要）が詳しく残る。実務では毎日の現金有高（実際の残高）と照合して、現金過不足がないか確認する。

現金出納帳の構造と記入方法

現金出納帳のフォーマット： 
日付 │ 摘要           │ 収入      │ 支出      │ 残高
─────┼───────────────┼───────────┼───────────┼──────────
5/1  │ 前月繰越       │           │           │  50,000
5/3  │ 売掛金回収     │  200,000  │           │ 250,000
5/7  │ 消耗品費払い   │           │    5,000  │ 245,000
5/10 │ 仕入代金払い   │           │  100,000  │ 145,000
5/28 │ 受取家賃入金   │   60,000  │           │ 205,000
5/31 │ 月次合計       │  260,000  │  105,000  │ 205,000
5/31 │ 次月繰越       │           │  205,000  │      0
     │ 合計           │  260,000  │  310,000  │
6/1  │ 前月繰越       │  205,000  │           │ 205,000
月末の締め・翌月繰越の手順： 
① 月末残高を計算：収入合計 − 支出合計 ＝ 月末残高
② 次月繰越行を支出欄に記入（残高を帳消しにする）
③ 収入合計と支出合計が一致する（合計欄で検算）
④ 翌月1日の前月繰越に同額を収入欄に記入
T字勘定との対応： 
       現金
─────────────────────────
前月残高    50,000│消耗品費     5,000
売掛金    200,000│仕入       100,000
受取家賃   60,000│
合計      310,000│合計       105,000→残高205,000

現金出納帳の収入合計・支出合計・月末残高は、総勘定元帳の現金勘定の借方合計・貸方合計・残高と一致する。

試験のキモ

簿記3級 過去問の第2問では、現金出納帳の記入・残高計算が出題される。

  1. 月末残高の計算：前月残高 ＋ 月中収入合計 − 月中支出合計 ＝ 月末残高
  2. 摘要欄の記入：「売掛金回収」「消耗品購入」など取引の内容を簡潔に書く
  3. 次月繰越と前月繰越の対応：月末残高を次月に持ち越す締め処理
  4. 現金過不足の扱い：実際有高と帳簿残高が合わない場合は「現金過不足」勘定を使う（別論点）
最大の失点原因は「残高欄の足し算・引き算のミス」だ。収入が入ったら加算、支出が出たら減算、というシンプルな計算を丁寧に積み上げることが正確な回答への道だ。

混同しやすい用語

帳簿対象記録する内容
現金出納帳現金勘定全般全ての現金入出金
小口現金出納帳小口現金のみ用度係管理の少額現金
当座預金出納帳当座預金勘定小切手振出・入金等
  • 現金出納帳 vs 小口現金出納帳：現金出納帳は会社全体の現金、小口現金出納帳は用度係が管理する少額現金のみ
  • 現金出納帳 vs 総勘定元帳：どちらも現金の動きを記録するが、出納帳は「摘要（理由）」が詳細

試験対策・関連リンク

簿記3級 仕訳 覚え方として「現金出納帳の残高欄は毎行更新」という意識で問題を解くと残高計算ミスが激減する。簿記3級 独学では実際に空のフォーマットを準備し、練習問題の取引を一行ずつ書き込む「書いて覚える」方式が最も定着が早い。簿記3級 過去問の第2問では現金出納帳・当座預金出納帳・売掛金元帳など複数の補助帳簿が出題されるため、各帳簿のフォーマットと記入ルールをセットで押さえておくと対応力が上がる。
