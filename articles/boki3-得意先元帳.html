得意先元帳とは何か

得意先元帳（とくいさきもとちょう）とは、売掛金元帳の別名であり、商品を掛で販売した得意先（販売先）ごとに売掛金の残高を管理する補助元帳だ。「得意先元帳 とは」「得意先元帳 売掛金元帳 違い」と検索されるほど、簿記3級 試験の第2問で「売掛金元帳」という呼称と混在して出題される重要な補助簿だ。

「得意先元帳」と「売掛金元帳」は呼び方が異なるだけで、同一の帳簿を指す。教科書・出版社によって呼称が異なるため、試験では両方の名称が出てくるが、同じものとして処理すればよい。「人名元帳（売掛金側）」と呼ぶ教科書もある。

なぜ「得意先」元帳というかというと、売掛金のある相手先を「得意先（お得意様）」と呼ぶ商習慣に由来する。仕入先（仕入れる相手）には買掛金、得意先（販売する相手）には売掛金という対応関係だ。

得意先元帳の記入パターン

得意先元帳の基本構造（人名別T字勘定形式）：

`` A商店（得意先元帳） B商店（得意先元帳） ────────────── ────────────── 借方 │ 貸方 借方 │ 貸方 ────────────── ────────────── 売上100,000│回収80,000 売上200,000│返品20,000 │残高20,000 │回収150,000 │残高30,000 ``

一覧表形式での記入：

`` 得意先元帳（4月分） ───────────────────────────────────── 得意先 │ 前月繰越 │ 掛売上 │ 回収等 │ 月末残高 ───────────────────────────────────── A商店 │ 20,000 │100,000 │ 80,000 │ 40,000 B商店 │ 0 │200,000 │170,000 │ 30,000 合計 │ 20,000 │300,000 │250,000 │ 70,000 ───────────────────────────────────── ↑ この合計が総勘定元帳の売掛金勘定残高70,000と一致する ``

試験のキモ

簿記3級 過去問の第2問では、得意先元帳（売掛金元帳）が以下のパターンで出題される。

  1. 「得意先元帳のA商店口座を記入しなさい」→売掛金元帳のA商店欄を記入
  2. 各月の増加（掛売上）と減少（回収・返品）を記入して残高を求める
  3. 「得意先元帳合計と総勘定元帳の売掛金が一致するか確認」→検算問題
  4. 補助元帳と総勘定元帳の関係：補助元帳の明細合計＝総勘定元帳の勘定残高

最もよくある混乱は「売掛金元帳と得意先元帳が別の帳簿だと思い込む」ことだ。試験で「得意先元帳を記入しなさい」と書かれていたら、それは「売掛金元帳と同じもの」と理解して処理しよう。

関連する元帳との比較

補助元帳別名管理内容
売掛金元帳得意先元帳、人名元帳（売掛金側）得意先別の売掛金残高
買掛金元帳仕入先元帳、人名元帳（買掛金側）仕入先別の買掛金残高
  • 得意先元帳 vs 売掛金元帳：完全に同一の帳簿。呼称の違いのみ
  • 得意先元帳 vs 仕入先元帳：得意先は販売相手（売掛金）、仕入先は購入相手（買掛金）の管理帳簿

試験対策・関連リンク

簿記3級 仕訳 覚え方として「得意先元帳＝売掛金元帳の別名」とシンプルに暗記する。教科書によって呼称が異なるが、試験では問題文の表現に従えばよい。簿記3級 独学・過去問・勉強方法として「得意先（販売先）→売掛金→得意先元帳」「仕入先（購入先）→買掛金→仕入先元帳」という流れで3つをセットで覚えると、補助元帳全体の体系が把握できる。簿記3級 過去問では第2問で「売掛金元帳（得意先元帳）に記入しなさい」という括弧書き付きの問題も出るため、両方の呼称に慣れておくことが重要だ。
