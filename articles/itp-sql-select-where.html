SQLの SELECT・WHEREとは？

データベースからデータを取り出す基本命令。SELECT で「何を」取り出すかを指定し、WHERE で「どの条件」のものだけを絞り込む。

🎬 こんなシーンを想像
社員データベースに5000人分のデータが入っている。「東京勤務・30歳以上の社員の名前と部署だけ取り出したい」。そんなとき、SQLでSELECT（何を）とWHERE（どの条件）を組み合わせて使う。
…この「列を選び・条件で絞る」SQL命令はどう書く？
📊 SELECT・WHEREの動き
📝 基本構文と各句の役割
SELECT 列名1, 列名2
FROM テーブル名
WHERE 列名 = '値';
-- 複数条件
WHERE 年齢 >= 30 AND 部署 = '営業';
SELECT 列名
取り出す列を指定。「*」で全列。カンマ区切りで複数指定可。
FROM テーブル名
どのテーブルから取得するかを指定。必須。
WHERE 条件
条件に合う行だけを絞り込む。省略すると全行が対象。
GROUP BY 列名
指定列でグループ化。COUNT・SUM等の集計と組み合わせる。
ORDER BY 列名
結果を指定列で並べ替え。ASC（昇順）／DESC（降順）。

WHERE の条件演算子：=（等しい）　>=<=（以上・以下）　LIKE '%文字%'（部分一致）　AND/OR（複数条件）

⚠️ ひっかけ注意ポイント
WHEREとHAVINGの違い
WHERE は行（個々のデータ）を絞り込む条件。
HAVING はGROUP BYでグループ化した後の集計結果を絞り込む条件。順序が違う。
SELECT の順序
書く順序は SELECT → FROM → WHERE → GROUP BY → HAVING → ORDER BY。
WHERE は FROM の後、GROUP BY の前に来る。
SELECT * の意味
「SELECT *」は全列を取得という意味。特定の列だけ取得するときは列名をカンマ区切りで指定する。
🧠 覚え方（無理やりゴロ）
SQL文の書き順は「セ・フ・ワ」
セレクト（SELECT）→ フロム（FROM）→ ワー（WHERE）

WHERE（絞り込み）と HAVING（グループ後の絞り込み）
W（Where）＝行（行単位で絞る）
H（Having）＝ハンパない量をグループ後に絞る
