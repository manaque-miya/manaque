分散とは何か

各データと平均との差（偏差）を2乗し、その平均を取った値が分散（Variance）だ。式は σ^2 = Σ(xi − μ)^2 / n と表せる。「データが平均のまわりにどれだけ散らばっているか」を数値化する指標だ。

💡 ポイント: 分散が小さい = データが平均の近くに密集している（安定）。分散が大きい = データが平均から遠く散らばっている（不安定）。平均が同じでも分散が違えばデータの性質は全く異なる。

サーバの応答時間を例にすると、「平均200ms・分散 4（標準偏差2ms）」と「平均200ms・分散 10000（標準偏差100ms）」では後者の方が応答が安定しない。SLA の管理では平均値だけでなく分散（ばらつき）も監視する。

木村さん（IT企業エンジニア1年目）が「AサーバとBサーバ、平均レスポンスは同じ200msなんですよ」と言った。先輩が「でもBは分散が100倍大きい、ユーザー体験は全然違う」と指摘し、木村さんは平均だけでは語れないシステムの安定性を理解した。

分散の計算例

データ: 2, 4, 4, 4, 5, 5, 7, 9

ステップ計算結果
平均μ(2+4+4+4+5+5+7+9) / 85
偏差の2乗合計(2-5)^2 + (4-5)^2×3 + (5-5)^2×2 + (7-5)^2 + (9-5)^29+3+0+4+16=32
分散σ^232 / 84

⚠️ 間違いやすいパターン: 偏差（xi − μ）の2乗を取らずに「偏差の平均」を計算すると必ず0になる（プラスとマイナスが打ち消される）。2乗することで散らばりを正の値として捉えるのが分散の核心。

ここが試験のキモ ✅

  • ✅ 分散 σ^2 = Σ(xi − μ)^2 / n（偏差の2乗の平均）
  • ✅ 分散の単位は元データの単位の2乗（cmのデータなら cm^2）
  • ✅ 標準偏差 σ = √σ^2（分散の平方根で元の単位に戻る）
  • ✅ 分散ゼロ = 全データが同じ値

分散と標準偏差の関係

分散は「2乗」のため単位が元データの単位の2乗になる。身長（cm）のデータなら分散は cm^2 となり、直感的に解釈しにくい。そこで分散の正の平方根を取った「標準偏差（σ）」を実際の散らばりの指標として使う。正規分布では平均±1σ の範囲に約68%のデータが入ることが知られている。

🎯 試験対策：分散の重要ポイント

基本情報技術者の過去問を独学で解く際、午前の統計問題で「どちらのデータが安定しているか」という比較問題が何度も出題される。分散が小さい方が安定という判断を即答できるようにしておけば得点源になる。

試験では「分散の公式」そのものより「平均が同じでも分散が違う2つのデータを比較する」問題が多い。「どちらのデータがより安定しているか」という問いには「分散が小さい方が安定」と即答できるようにしておく。

品質管理の6σ（シックスシグマ）という概念もある。μ ± 6σ の範囲外に収まる不良率を100万件に3〜4件以下に抑えることを目標にする手法だ。試験ではこのレベルまで詳細に問われることは少ないが、「σが小さいほど品質が安定している」という概念は覚えておく。
