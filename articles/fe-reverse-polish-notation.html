逆ポーランド記法とは何か

「演算子をオペランドの後ろに書く記法」が逆ポーランド記法（RPN: Reverse Polish Notation、後置記法）だ。通常の 3 + 4 を 3 4 + と書く。括弧が不要で、スタックを使って機械的に計算できるという性質から、コンパイラの中間コード・電卓・JVM（Java仮想機械）のバイトコードで広く採用されている。

💡 ポイント: 逆ポーランド記法の計算は「数値ならスタックに push、演算子なら2つ pop して計算し結果を push」というルール1つで機械的に実行できる。

木村さん（IT企業エンジニア1年目）が過去問で「3 4 2 * +」の値を聞かれ、「え、これどこから計算するの」と焦った。スタックに押し込んでいく手順を先輩に実演してもらい、「数字は積む、記号は2つ出して計算して積む——これだけか」と拍子抜けするほどシンプルな規則に気づいた。

「基本情報技術者 過去問」では「中置記法の式を逆ポーランド記法に変換せよ」または「逆ポーランド式の値を計算せよ」という問題が頻出中の頻出だ。どちらも手順が決まっているのでスタックの動きを書ける人は確実に点が取れる。

3種類の記法の比較

記法演算子の位置例特徴
中置記法（通常）2つのオペランドの間3 + 4人間が読みやすい・括弧が必要
前置記法（ポーランド）オペランドの前+ 3 4括弧不要・LISPで採用
後置記法（逆ポーランド）オペランドの後3 4 +括弧不要・スタック計算が容易

⚠️ 間違いやすいパターン: 「ポーランド記法（前置）」と「逆ポーランド記法（後置）」を混同しやすい。前置は演算子が先頭（+ 3 4）、後置は演算子が末尾（3 4 +）だ。試験では「逆ポーランド記法はどれか」という問いに前置記法が誤りの選択肢として混ぜ込まれる。

逆ポーランド記法への変換手順

中置式 3 + 4 * 2 を逆ポーランド記法に変換する（演算子スタック法）：

入力：3 + 4 * 2

手順：

  1. '3' → 数値なので出力： 出力: [3] スタック: []
  2. '+' → 演算子、スタックに積む 出力: [3] スタック: [+]
  3. '4' → 数値なので出力： 出力: [3,4] スタック: [+]
  4. '' → '+' より優先度高いのでスタックに積む スタック: [+,]
  5. '2' → 数値なので出力： 出力: [3,4,2] スタック: [+,*]
  6. 終了 → スタックを全て出力：出力: [3,4,2,*,+]

結果：3 4 2 * +

逆ポーランド式の計算手順

逆ポーランド式 3 4 2 * + をスタックで計算する：

入力：3 4 2 * +

手順：

  1. '3' → push スタック: [3]
  2. '4' → push スタック: [3,4]
  3. '2' → push スタック: [3,4,2]
  4. '' → pop 2個（4と2）→ 42=8 → push スタック: [3,8]
  5. '+' → pop 2個（3と8）→ 3+8=11 → push スタック: [11]

結果：11（= 3 + 4*2 の正しい値）

ここが試験のキモ ✅

  • ✅ 逆ポーランド記法＝「演算子を後ろに書く後置記法」
  • ✅ スタック計算：数値→push、演算子→2個pop・計算・push の繰り返し
  • ✅ 括弧なしで演算子優先度を自然に表現できる
  • ✅ 「基本情報技術者 過去問」では変換問題・計算問題の両方が頻出
  • ✅ 「基本情報技術者 独学」ではスタックの動きを図示しながら手計算する練習が最速
  • ✅ 前置記法（ポーランド記法）と逆ポーランド（後置）の区別は必須

計算問題のトレース練習

5 1 2 + 4 * + 3 - をスタック計算する：

push 5 [5] push 1 [5,1] push 2 [5,1,2] '+'→pop 1,2→1+2=3 push [5,3] push 4 [5,3,4] ''→pop 3,4→34=12 push [5,12] '+'→pop 5,12→5+12=17 push [17] push 3 [17,3] '-'→pop 17,3→17-3=14 push [14]

結果：14

中置に戻すと 5 + (1+2)*4 - 3 = 5 + 12 - 3 = 14 で正解が確認できる。

🎯 試験対策：逆ポーランド記法の重要ポイント

「基本情報技術者 過去問・午前午後」での出題は「中置記法の式を後置記法に変換したものはどれか」と「後置記法の式を評価した結果はどれか」の2パターンに集約される。「基本情報技術者 独学・何時間」かけるにせよ、スタックのマス目トレースを5〜10問練習すれば本番で焦ることはない。

変換問題は「演算子スタック法（シャンティング・ヤード法）」を練習する。優先度が低い演算子は後でスタックから出てくるので出力が後になる、という原理を掴むと頭で追えるようになる。

計算問題はスタックの動きをマス目で書いて機械的に処理するだけで必ず正解できる。手を動かす練習を 5〜10 問こなしておくと試験本番でも焦らない。

「逆ポーランド記法 とは」の直問では「演算子をオペランドの後に記述する後置記法で、スタックを用いて順次計算できる記法」が正答文になる。「演算子を先頭に書く記法」「括弧を多用して優先度を示す記法」は誤りのパターンだ。

「基本情報技術者 科目B・午後問題」ではスタックを使うアルゴリズム問題が出題されることがあり、逆ポーランド記法の計算プロセスはスタック動作の理解チェックとしても機能する。スタックの push/pop 操作を正確にトレースできるかどうかがアルゴリズム問題の得点に直結する。
