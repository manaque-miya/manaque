買掛金元帳とは何か

買掛金元帳（かいかけきんもとちょう）とは、総勘定元帳の「買掛金」勘定を仕入先別に詳細管理する補助元帳です。「仕入先元帳（しいれさきもとちょう）」とも呼ばれます。

買掛金元帳の仕組み

【買掛金元帳（B商店）】
日付 | 摘要    | 借方（支払） | 貸方（仕入） | 残高
5/1 | 前月繰越 |            |            | 80,000
5/8 | 仕入    |            | 60,000     | 140,000
5/25| 支払    | 80,000     |            | 60,000
5/31| 次月繰越 | 60,000     |            | 0

買掛金元帳は「借方＝支払・返品、貸方＝仕入」という点で、売掛金元帳と借方・貸方が逆になります。

試験のキモ

仕入先ごとの買掛金残高を把握することで、支払管理が効率化されます。

買掛金元帳全取引先合計＝総勘定元帳の買掛金残高、の一致確認が重要です。

混同しやすい用語

  • 買掛金元帳 vs 売掛金元帳：買掛金元帳は仕入先（払う側）、売掛金元帳は得意先（もらう側）
  • 買掛金元帳の借方 vs 貸方：借方が支払・減少、貸方が仕入・増加（負債なので増加は貸方）
