固定資産の売却とは何か

固定資産の売却（こていしさんのばいきゃく）とは、建物・車両運搬具・備品などの固定資産を売り払うことで、売却価額と帳簿価額の差額として「固定資産売却益（収益）」または「固定資産売却損（費用）」が発生する取引だ。「固定資産の売却 仕訳 簿記3級」「固定資産売却益 固定資産売却損 計算」「車両売却 仕訳 減価償却」と検索されるほど、簿記3級 試験の第1問・第3問で頻出する発展的な固定資産処理だ。

固定資産は購入後に毎年減価償却をするため、売却時の「帳簿価額（簿価）」は取得原価より低くなっている。売却価額が帳簿価額より高ければ「固定資産売却益」、低ければ「固定資産売却損」が生じる。簿記3級では「年度途中での売却」が出題されることがあり、その場合は売却月までの減価償却費も計上してから帳簿価額を確定させる。

固定資産の売却の仕訳パターン

期末（年度末）に固定資産を売却したとき（売却益が出た場合）：

``` 例：取得原価500,000円、減価償却累計額300,000円の備品を250,000円で売却 帳簿価額：500,000－300,000＝200,000円 売却益：250,000－200,000＝50,000円

（借）現金　　　　　　250,000 減価償却累計額　 300,000 ／（貸）備品　　　　　 500,000 固定資産売却益 50,000 ```

期末に固定資産を売却したとき（売却損が出た場合）：

``` 例：取得原価300,000円、減価償却累計額100,000円の車両を180,000円で売却 帳簿価額：300,000－100,000＝200,000円 売却損：200,000－180,000＝20,000円

（借）現金　　　　　　180,000 減価償却累計額　 100,000 固定資産売却損　 20,000 ／（貸）車両運搬具　　 300,000 ```

年度途中で売却したとき（期中売却・当期分の減価償却を計上）：

`` 例：4月1日始まりの会計年度で、10月1日（6か月後）に車両を売却 年間減価償却費：120,000円→6か月分：60,000円を計上 （借）減価償却費 60,000 ／（貸）減価償却累計額 60,000 その後で売却仕訳を行う ``

試験のキモ

簿記3級 過去問の第1問・第3問では、固定資産の売却が以下のパターンで出題される。

  1. 「期末売却」→累計額を全額取り崩し、売却益・損を計算：帳簿価額と売却価額の差額を確認
  2. 「期中売却」→当期分の減価償却費を計上してから売却：売却月までの月数を月割計算
  3. 「売却益か売却損か」→売却価額と帳簿価額を比較：高ければ益、低ければ損
  4. 「代金の受取方法」→現金・普通預金・未収入金など問題文で確認

最もよくある失点は「減価償却累計額を取り崩し忘れる」か「売却益と売却損を逆に書く」ことだ。売却時は「固定資産（貸方）と減価償却累計額（借方）を同時に消す」という処理を型として覚えよう。また代金が後払いの場合は現金ではなく未収入金（資産）を使う。

固定資産の売却と関連する勘定の比較

場面仕訳の方向使う勘定
期末売却（売却益）売却益→貸方固定資産売却益（収益）
期末売却（売却損）売却損→借方固定資産売却損（費用）
期中売却売却前に減価償却費計上減価償却費・減価償却累計額
代金後払い未収入金（借方）で受取未収入金（資産）
  • 固定資産売却益 vs 固定資産売却損：売却価額が帳簿価額より高ければ益（収益）、低ければ損（費用）
  • 固定資産の売却 vs 減価償却：減価償却は毎期の費用配分、売却は処分時の一括処理

試験対策・関連リンク

簿記3級 仕訳 覚え方として「固定資産の売却＝固定資産を消す＋減価償却累計額を消す＋差額が益か損」という3段階で考えると仕訳を組み立てやすい。簿記3級 独学では「取得原価」「減価償却累計額」「帳簿価額（簿価）」「売却価額」の4つの数字を問題文から読み取って整理してから仕訳を書く習慣をつけよう。簿記3級 勉強方法として期中売却の問題は「売却月までの月数を確認→当期分の減価償却費を計上→売却仕訳」という3ステップで処理すると落ち着いて解ける。簿記3級 過去問・勉強方法・独学・仕訳の練習では第1問・第3問ともに「備品（または車両）○○円を売却した」という問題が典型なので、固定資産の取り崩しパターンを反復練習して確実に得点しよう。
