仕入先元帳とは何か

仕入先元帳（しいれさきもとちょう）とは、買掛金元帳の別名であり、商品を掛で仕入れた仕入先（購入先）ごとに買掛金の残高を管理する補助元帳だ。「仕入先元帳 とは」「仕入先元帳 買掛金元帳 違い」と検索されるほど、簿記3級 試験の第2問で「買掛金元帳」と混在して出題される補助簿だ。

「仕入先元帳」と「買掛金元帳」は呼び方が異なるだけで、同一の帳簿を指す。「人名元帳（買掛金側）」と呼ぶ教科書もある。得意先元帳（売掛金元帳）が販売側の管理なら、仕入先元帳（買掛金元帳）は購入側の管理だ。

なぜ「仕入先」元帳というかというと、買掛金のある相手先を「仕入先（仕入れる相手）」と呼ぶ商習慣に由来する。簿記3級 独学では「得意先元帳（売掛金元帳）」と「仕入先元帳（買掛金元帳）」をペアで理解するのが最も効率的だ。

仕入先元帳の記入パターン

仕入先元帳の基本構造（人名別T字勘定形式）： 
  A仕入先（仕入先元帳）                B仕入先（仕入先元帳）
  ──────────────                        ──────────────
  借方 │ 貸方                           借方 │ 貸方
  ──────────────                        ──────────────
  支払80,000│仕入100,000              支払200,000│仕入250,000
  返品10,000│                                    │残高50,000
  残高10,000│
一覧表形式での記入： 
仕入先元帳（4月分）
  ─────────────────────────────────────
  仕入先 │ 前月繰越 │ 掛仕入 │ 支払等 │ 月末残高
  ─────────────────────────────────────
  A仕入先│   20,000 │100,000 │ 90,000 │  30,000
  B仕入先│    0     │250,000 │200,000 │  50,000
  合計   │   20,000 │350,000 │290,000 │  80,000
  ─────────────────────────────────────
  ↑ この合計が総勘定元帳の買掛金勘定残高80,000と一致する

試験のキモ

簿記3級 過去問の第2問では、仕入先元帳（買掛金元帳）が以下のパターンで出題される。

  1. 「仕入先元帳のB仕入先口座を記入しなさい」→買掛金元帳のB仕入先欄を記入
  2. 各月の増加（掛仕入）と減少（支払・返品）を記入して残高を求める
  3. 補助元帳の全仕入先合計と総勘定元帳の買掛金勘定残高が一致するかの検算
  4. 増加は貸方（負債増加）、減少は借方（負債減少）の方向を正確に記入
最大の注意点は「仕入先元帳（買掛金元帳）の増加は貸方」という方向だ。売掛金元帳（資産）は増加が借方だが、買掛金元帳（負債）は増加が貸方と逆になる。この違いを見落とすと元帳全体の残高がずれてしまう。

関連する元帳との比較

補助元帳別名増加の方向減少の方向
仕入先元帳（買掛金元帳）人名元帳（買掛金側）貸方（負債増加）借方（負債減少）
得意先元帳（売掛金元帳）人名元帳（売掛金側）借方（資産増加）貸方（資産減少）
  • 仕入先元帳 vs 買掛金元帳：完全に同一の帳簿。呼称の違いのみ
  • 仕入先元帳 vs 得意先元帳：仕入先は購入相手（負債）、得意先は販売相手（資産）の管理

試験対策・関連リンク

簿記3級 仕訳 覚え方として「仕入先元帳＝買掛金元帳の別名」とシンプルに暗記する。試験では問題文の表現に従えばよく、「仕入先元帳」と書かれていたら「買掛金元帳と同じもの」と理解して処理する。簿記3級 勉強方法として補助元帳の問題は「得意先元帳（売掛金・資産・増加が借方）」「仕入先元帳（買掛金・負債・増加が貸方）」という対比表を作って整理すると、方向の混乱がなくなる。簿記3級 過去問では「売掛金元帳（得意先元帳）と買掛金元帳（仕入先元帳）の両方を記入しなさい」という問題も出るため、両者の方向の違いを体で覚えておくことが得点への近道だ。
