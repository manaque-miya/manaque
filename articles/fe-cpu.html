CPU（中央演算処理装置）コンピュータ構成基本情報技術者

CPUとは何か

コンピュータの中で「命令を解釈して実行する」中核の装置が CPU（Central Processing Unit、中央演算処理装置）だ。プログラムはメモリに格納されており、CPU がそこから命令を1つずつ取り出し（フェッチ）、解読（デコード）し、実行する。この繰り返しがプログラムの動作そのものだ。

💡 ポイント: CPU は「コンピュータの脳」。構成要素は ALU（算術論理演算装置）・制御装置・レジスタ・キャッシュメモリ の4種類。これを丸ごと覚えておくと構成問題を一気に解ける。

「基本情報技術者 過去問」では「CPUの構成要素として適切なものを選べ」という形の選択問題が出る。ALU は演算、制御装置は指揮、レジスタは CPU 内の高速一時記憶、キャッシュは主記憶との速度差を埋める緩衝役と、それぞれ役割が明確に分かれている。

CPUの構成要素と役割

構成要素正式名称主な役割
ALU算術論理演算装置加減乗除・AND/OR/XOR などの演算を実行
制御装置Control Unit命令を解読して各部に制御信号を送る
レジスタRegisterCPU 内部の超高速作業領域（数十個）
キャッシュCache Memory主記憶との速度差を埋める高速バッファ
⚠️ 間違いやすいパターン: 「CPU＝演算だけする装置」という誤解が多い。制御装置や各種レジスタも CPU の内部に含まれる。試験では「CPUに含まれないものはどれか」という形で補助記憶（HDD/SSD）や主記憶（RAM）が選択肢に紛れ込む。

ここが試験のキモ ✅

✅ CPU の構成要素は「ALU・制御装置・レジスタ・キャッシュ」の4点セット
✅ 主記憶（RAM）は CPU の外部にある別装置（CPU 構成要素ではない）
✅ 性能指標は「クロック周波数（Hz）・コア数・キャッシュサイズ」
✅ 「マルチコア」＝1チップ内に複数の CPU コアを搭載すること
✅ 「基本情報技術者 独学」では CPU → 命令サイクル → パイプラインの順で学ぶのが定石

マルチコアと性能向上

クロック周波数（1秒あたりの処理回数）は 2005 年頃から物理的な限界（熱・電力）で頭打ちになった。その後は 1 チップに複数のコアを搭載する「マルチコア」化が主流になる。2 コアなら単純な並列処理は 2 倍速になるが、プログラムが並列処理に対応していないと 1 コア分の速度しか出ない点（アムダールの法則）も試験頻出だ。

│        L2キャッシュ         │

🎯 試験対策：CPUの重要ポイント

「基本情報技術者 科目B・午後問題」では CPU 動作を前提にしたアルゴリズム問題が出る。「命令がどの順序で実行されるか」「レジスタの値がどう変化するか」をトレースできることが求められる。

科目A（旧午前）では「CPU の構成要素と役割」「クロック周波数・MIPS の計算」「パイプライン処理のスループット計算」が頻出だ。特に「MIPS = クロック周波数 ÷ CPI ÷ 10^6」という計算公式は毎年のように出題される。

「基本情報技術者 勉強方法」として、CPU 関連の単語は単独で覚えるより「CPU → 命令サイクル → パイプライン → キャッシュ → 仮想記憶」という流れで体系的に学ぶと記憶が定着しやすい。
