分数式数と式（高校）数学検定

分数式とは何か

「分母に文字を含む式」が分数式だ。(x＋1)/(x−1) や 2/(x²−4) のように、分母が多項式になっている式を指す。普通の分数（1/2 など）と同じように通分・約分・四則演算が行えるが、「分母が 0 になる値では定義されない」という条件が常に伴う点が重要だ。

💡 ポイント: 分数式の計算ルールは通常の分数と同じ——約分は「分子と分母を共通因数で割る」、通分は「分母の最小公倍式を探して揃える」。ただし分母に文字があるため、因数分解が計算の前提になることが多い。

分数式の基本演算

約分（共通因数を見つけて消す）:

(x²－1)/(x＋1) ＝ (x＋1)(x－1)/(x＋1) ＝ x－1（ただし x≠−1）

乗法（分子同士・分母同士を掛ける）:

(2x)/(x＋1) × (x＋1)/(x²) ＝ 2x(x＋1) / (x²(x＋1)) ＝ 2/x（x≠0, −1）

除法（割る分数の逆数を掛ける）:

(x＋1)/x ÷ (x²－1)/x² ＝ (x＋1)/x × x²/(x²－1) ＝ x/(x－1)（x≠0, ±1）

加減（通分して分母を揃える）:

1/(x＋1) ＋ 1/(x－1) ＝ (x－1)/((x＋1)(x－1)) ＋ (x＋1)/((x＋1)(x－1)) ＝ 2x/(x²－1)

⚠️ 間違いやすいパターン: 「約分できるのに因数分解せずにそのまま計算を進める」ミスが最多発だ。分子・分母を因数分解して共通因数を探してから演算するのが正手順。また「(x＋1)/(x＋1) を約分するとき、x＝−1 の除外条件を書き忘れる」ケースも多い——除外条件は結果の下に「ただし x≠○○」として必ず付記する。

ここが試験のキモ ✅

✅ 計算前に分子・分母を因数分解して共通因数の有無を確認する
✅ 約分したら「ただし分母＝0となる値を除く」条件を付記する
✅ 通分の際は「共通分母（最小公倍式）を探す」——数の通分と同じ発想

分数式が使われる場面

分野登場する分数式の例
方程式の変形分母を払う操作（両辺に LCM を掛ける）
有理関数のグラフy＝1/x などの漸近線の議論
三角関数の変形sinθ/cosθ＝tanθ など
微積分部分分数分解（積分計算）

🎯 試験対策：分数式の重要ポイント

数学検定準2級〜2級の1次では「分数式を計算して整理せよ」問題が頻出だ。複数の分数式を加減する場合の最短戦略は「分母を因数分解して最小公倍式を求め → 各分数を通分し → 分子をまとめ → 約分できないか再確認する」の4ステップだ。

2次（記述式）では「分数式を含む方程式を解く」問題で、両辺に LCM（分母の最小公倍式）を掛けて分母を払う操作が必要になる。この操作で余分な解（分母が 0 になる値）が導入される可能性があるため、解を得た後に必ず「分母が 0 になっていないか確認する」ステップを答案に明示すること。
