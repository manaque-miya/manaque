旅費交通費とは何か

旅費交通費（りょひこうつうひ）とは、業務に関連する電車・バス・タクシー代、出張の宿泊費・新幹線代などを計上する費用科目です。

旅費交通費の仕訳と仕組み

``` 例1：営業担当者の電車代1,800円を現金で支払った 借方：旅費交通費 1,800円 ／ 貸方：現金 1,800円

例2：出張費25,000円を仮払いしていたところ、 実費が22,000円で残額3,000円が返金された 借方：旅費交通費 22,000円 借方：現金 3,000円 ／ 貸方：仮払金 25,000円 ```

試験のキモ

仮払金（かりばらいきん）：出張前に概算金額を渡す際に使う資産科目。実費確定後に精算します。

``` 出張前の仮払い： 借方：仮払金 25,000円 ／ 貸方：現金 25,000円

精算時（実費22,000円・返金3,000円）： 借方：旅費交通費 22,000円 借方：現金 3,000円 ／ 貸方：仮払金 25,000円 ```

混同しやすい用語

  • 旅費交通費 vs 仮払金：旅費交通費は費用（PL）、仮払金は資産（BS）
  • 仮払金 vs 前払金：仮払金は出張費などの概算前払い、前払金は商品購入の手付金
