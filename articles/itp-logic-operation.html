論理演算とは？

コンピュータの判断の根本。「1か0か」「真か偽か」をAND・OR・NOTで組み合わせる演算。

🎬 こんなシーンを想像
会員サイトへのログイン判定。「メールアドレスが正しい」AND「パスワードが正しい」→ 両方が正しい時だけログイン成功。片方だけではダメ。
→ これがAND（論理積）の動き！日常に溢れている。
🔢 4つの基本演算
AND（論理積）
両方が1（真）のときだけ結果が1。
「A かつ B」
1 AND 1 = 1
1 AND 0 = 0
OR（論理和）
どちらか1つでも1なら結果が1。
「A または B」
1 OR 0 = 1
0 OR 0 = 0
NOT（否定）
1を0に、0を1に反転させる。
「A ではない」
NOT 1 = 0
NOT 0 = 1
XOR（排他的論理和）
2つが異なるときだけ1。
「どちらか一方のみ」
1 XOR 0 = 1
1 XOR 1 = 0

⚠️ ひっかけ注意ポイント
XORとORの違い
OR は「どちらか1つ以上が1なら1（両方1でも1）」。XOR は「ちょうど1つだけが1のとき1（両方1なら0）」。「排他的」＝どちらか一方のみという点がポイント。
AND と掛け算は違う
ANDは論理演算（1か0しかない）で算術の掛け算ではない。1×1=1 は同じ結果だが、概念が別物。混同しないよう注意。
「NOR」「NAND」も出題されることがある
NAND＝AND の否定（AND した結果を NOT）。NOR＝OR の否定。「N＝否定（NOT）」が頭についていると覚える。
🧠 覚え方（無理やりゴロ）
AND＝アンド（安堵）するのは両方1の時だけ
「A and B どちらも正解して安堵（あんど）！」

OR＝どちらか1つで「おー！」
NOT＝「の」っと（NOT）きたら逆にする
XOR＝エックスオア＝差（ちがい）だけが1
