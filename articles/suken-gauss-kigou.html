ガウス記号とは何か

中村さん（中学3年生・数学検定3級受験）が「[−2.5] って −2 じゃないの？」と首をかしげた。先生は「数直線で −2.5 より左にある整数のうち一番右のもの——それが −3 だよ」とひと言。中村さんはその瞬間、ガウス記号の本質をつかんだ。

実数 x に対して「x を超えない最大の整数」を表す記号がガウス記号 [x] だ。「床関数（floor function）」とも呼ばれる。整数そのものの値はそのまま、小数部分は切り捨てる——というイメージで理解できるが、負の数では直感と逆の結果になるため要注意だ。数学検定準1級の整数・数列問題でよく登場する記号だ。

💡 ポイント: [x] の定義は「x を超えない最大の整数」だ。「x に最も近い整数（四捨五入）」ではない。[3.7] ＝ 3（3.7 を超えない整数で最大のもの）、[−2.5] ＝ −3（−2.5 を超えない整数で最大のもの ——−2 は −2.5 より大きいので不可）。「超えない」の方向が鍵だ。

ガウス記号の値と例

典型的な計算例:

x の値[x] の値理由
33整数はそのまま
3.733 ≦ 3.7 ＜ 4
0.9900 ≦ 0.99 ＜ 1
−2.5−3−3 ≦ −2.5 ＜ −2
−3−3整数はそのまま
−0.1−1−1 ≦ −0.1 ＜ 0

[x] の基本性質:

  • [x] ≦ x ＜ [x] ＋ 1（定義の言い換え）
  • x ＝ [x] ＋ {x}（{x} は x の小数部分、0 ≦ {x} ＜ 1）
  • x が整数なら [x] ＝ x

⚠️ 間違いやすいパターン: 最大の失敗は負の数での計算だ。「[−2.5] ＝ −2」と答えてしまうケースが非常に多い——これは「絶対値で切り捨てて符号をつけ直す」という誤った操作をしているためだ。正しくは [−2.5] ＝ −3。数直線上で「x より左にある（x 以下の）整数の中で最大のもの」という視覚的なイメージを使うと確実だ。また「[3.7] ＝ 4（四捨五入）」という混同も頻出——ガウス記号は四捨五入ではなく「切り捨て（ただし負の方向に）」だ。

ここが試験のキモ ✅

  • ✅ [x] ＝「x を超えない最大の整数」——四捨五入ではなく「床（floor）」
  • ✅ 負の数は直感に反する：[−2.5] ＝ −3（−2 ではない）
  • ✅ x が整数のとき [x] ＝ x、[x] ≦ x ＜ [x] ＋ 1

ガウス記号を使った整数論の問題

ガウス記号は「1 から n までの整数のうち k の倍数の個数 ＝ [n/k]」という応用がある。たとえば「1 から 100 までの整数のうち 7 の倍数の個数は？」→ [100/7] ＝ [14.28…] ＝ 14 個。この応用は数学検定の整数問題でよく使われる。

また「n! を素数 p で何回割れるか（p の指数）」を求める公式でもガウス記号が使われる：

指数 ＝ [n/p] ＋ [n/p²] ＋ [n/p³] ＋ ⋯

🎯 試験対策：ガウス記号の重要ポイント

数学検定準1級の整数分野では「方程式 [x] ＝ ○○ を満たす x の範囲を求めよ」「[f(x)] ＝ k のグラフを描け（階段関数）」といった問題が出る。定義に戻って「[x] ＝ n ならば n ≦ x ＜ n ＋ 1」という不等式に直すアプローチが基本解法だ。

数学検定 過去問・勉強方法・独学で対策する場合、正の数と負の数の両方で 5〜10 例を実際に計算して確認する手順が定着を早める。特に −1 ＜ x ＜ 0 の区間（[x] ＝ −1 になる領域）を数直線で視覚的に確認しておくことが、本番での計算ミス防止に直結する。
