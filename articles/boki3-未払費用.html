未払費用とは何か

未払費用（みばらいひよう）とは、当期に発生したにもかかわらず期末時点でまだ支払っていない費用を、経過勘定として計上する負債勘定だ。「未払費用 とは」「未払費用 仕訳 簿記3級」「未払費用 未払金 違い」と検索されるほど、簿記3級 試験の第3問・決算整理仕訳で頻出する重要な経過勘定の一つだ。

発生主義の原則に従い、費用は現金の支払いに関係なく「発生した期間」に計上しなければならない。たとえば借入金の利息を半年に1度後払いする契約で3月決算の場合、4〜3月の当期分のうち「まだ支払っていない月分」は支払義務が発生しており、「未払費用（負債）」として計上する。

「費用の見越し計上」とも呼ばれる。未払費用を計上した翌期首には再振替仕訳を行って戻す。具体例は未払家賃・未払地代・未払利息（支払利息の未払分）・未払給料などだ。

未払費用の仕訳パターン

決算整理仕訳（未払利息の計上）：

``` 例：3月決算。借入金200万円（年利率3%、利息は毎年9月に支払） 当期は10月〜3月の6か月分が未払 未払額＝200万×3%×6/12＝30,000円

決算時：（借）支払利息 30,000 ／（貸）未払費用 30,000 ```

翌期首の再振替仕訳：

`` 翌期首：（借）未払費用 30,000 ／（貸）支払利息 30,000 （→ 9月に利息全額を支払う時点で「支払利息」で処理する） ``

未払家賃の場合：

`` 例：毎月末に家賃20,000円を支払う契約。3月分が4月支払い予定 決算時：（借）支払家賃 20,000 ／（貸）未払費用 20,000 ``

T字勘定での未払費用の動き：

`` 未払費用（負債） ───────────────────────── 再振替（翌期首）30,000│支払利息（見越）30,000 │残高 30,000 （期首に逆仕訳で消える） ``

試験のキモ

簿記3級 過去問の第3問（試算表・決算整理）では、未払費用の計上が繰り返し出題される。

  1. 「当期発生・未払いの利息・家賃が○○円ある」→（借）支払利息（or支払家賃）／（貸）未払費用
  2. 月割計算で当期分を算出：借入金元本×年利率×月数/12 で未払利息を計算する
  3. 再振替仕訳：翌期首に逆仕訳（（借）未払費用 ／（貸）支払利息）を行う
  4. 未払金との区別：未払費用は経過勘定（時間配分）、未払金は商品以外の購入代金未払い

最もよくある失点は「（借）側と（貸）側が逆になる」ことだ。費用の見越しでは「費用勘定（借方）を増やし、未払費用（貸方・負債）を計上する」という方向を徹底しよう。

混同しやすい用語との違い

勘定属性内容
未払費用負債当期発生・未払いの費用（経過勘定）
未払金負債商品以外の購入代金の未払い
未払法人税等負債法人税等の未納付額
前払費用資産次期分の費用・前払済み（経過勘定）
  • 未払費用 vs 未払金：未払費用は「期間配分で時間ずれが生じた費用」、未払金は「固定資産等の購入代金の未払い」
  • 未払費用 vs 前払費用：未払費用は当期分・未払い（負債）、前払費用は次期分・前払済み（資産）

試験対策・関連リンク

簿記3級 仕訳 覚え方として「未払費用＝当期分なのにまだ払っていない費用＝負債（将来払う義務）」と一言で覚える。簿記3級 独学では未払費用と未収収益のペア（どちらも「見越し計上」）を一緒に学習すると混乱が減る。「未払費用→費用（借方）増加・未払費用（貸方）計上」「未収収益→未収収益（借方）計上・収益（貸方）増加」と借貸の方向セットで覚えよう。簿記3級 勉強方法として月割計算の練習は不可欠で、「借入金元本×年利率×未払月数÷12」という計算手順を素早く行えるよう反復練習するのが得点への近道だ。簿記3級 過去問・勉強方法・独学・仕訳のすべての観点から「借入金○○円に対する利息（年利率○%）のうち○か月分が未払い」という問題形式に慣れておくことが高得点の近道だ。
