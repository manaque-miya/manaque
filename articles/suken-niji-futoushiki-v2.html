二次不等式とは何か

中村さん（中学3年生・数学検定3級受験）が「x²−5x＋6＞0 って、解の公式使えばいい？」と問いかけた。「まず交点を求める、でも解はグラフが軸より上にある範囲だよ」と先生が放物線を素早くスケッチすると、中村さんは「グラフで読むのか！」と目が輝いた。

二次不等式とは、x²を含む不等式——x²−5x＋6＞0 や 2x²＋3x−2≦0 といった形だ。解法の核心は「グラフを使う」こと——二次関数のグラフが x 軸より上にある（＞0）か下にある（＜0）かで解の範囲を読み取る。数値計算だけで解こうとすると間違いやすいため、グラフのイメージを常に持って解くことが重要だ。

💡 ポイント: 二次不等式の解法は「① 二次方程式の解（x軸との交点）を求める → ② グラフの開き方（上に凸か下に凸か）を確認 → ③ グラフが 0 より上または下になる x の範囲を読む」の3ステップ。

二次不等式の解法パターン

例題1（下に凸、D＞0）: x²−5x＋6＞0 を解け

→ x²−5x＋6＝0 を解く → (x−2)(x−3)＝0 → x＝2, 3 → グラフは下に凸（a＝1＞0）、x軸より上の範囲が解 → x＜2 または x＞3

例題2（下に凸、D＞0）: x²−5x＋6＜0 を解け

→ 交点は同じく x＝2, 3 → グラフが x 軸より下（内側）の範囲 → 2＜x＜3

a の符号不等号解の形
a＞0（下に凸）f(x)＞0外側（x＜α または x＞β）
a＞0（下に凸）f(x)＜0内側（α＜x＜β）
a＜0（上に凸）f(x)＞0内側（α＜x＜β）
a＜0（上に凸）f(x)＜0外側（x＜α または x＞β）

⚠️ 間違いやすいパターン: a＜0（上に凸）の二次不等式で「外側が f＞0」と思い込むミスが多い。上に凸のグラフは頂点付近が高く、両端が低いため「交点の内側（間の範囲）で f(x)＞0」になる。グラフを書いて確認する習慣が重要だ。

ここが試験のキモ ✅

  • ✅ 先に二次方程式を解いて x 軸との交点（境界点）を求める
  • ✅ a の符号でグラフの形（上/下凸）を確認してから解の範囲を決める
  • ✅ 「外側」「内側」という言葉でイメージを持つ——暗記より理解が有効

特殊なケース

判別式 D の値グラフの形f(x)＞0 の解（a＞0）f(x)＜0 の解（a＞0）
D＞0（2交点）x軸と2点交差外側の2範囲間の範囲
D＝0（接点）x軸に接触接点以外の全実数解なし
D＜0（交点なし）x軸と交わらない全実数解なし

🎯 試験対策：二次不等式の重要ポイント

数学検定準2級では「二次不等式と一次不等式を連立する」問題が出題される。例えば x²−5x＋6＞0 かつ x＜4 の場合、二次不等式の解「x＜2 または x＞3」と一次不等式の解「x＜4」の共通範囲を取り「x＜2 または 3＜x＜4」となる。

2次（記述式）では「パラメータ k を含む二次不等式が常に成立する条件」問題が頻出だ。「f(x)＞0 がすべての実数で成立する ⟺ a＞0 かつ D＜0」という条件をグラフで説明しながら答案を書くと論述の評価が高くなる。数学検定 過去問・勉強方法・独学では放物線スケッチと場合分け表をセットで練習するのが最短ルートだ。
