当座借越とは何か

当座借越（とうざかりこし）とは、当座預金の残高を超えて小切手を振り出した場合に、銀行が一定限度まで立て替えてくれる仕組みのことです。「当座借越 とは」「当座借越 仕訳」と検索されるほど、簿記3級 試験の決算整理で欠かせない論点です。

当座預金の残高を超えた部分は、銀行が立て替えてくれることになりますが、これは事実上の短期借入です。したがって、当座借越は負債として処理します。期中は「当座預金のマイナス残高」として記録し、決算整理で「当座借越（または借入金）」という負債勘定に振り替えます。

当座借越の仕訳と仕組み

前提：当座預金残高 300,000円（借方残）のとき、500,000円の小切手を振り出した

``` 期中（一勘定制の場合）： 借方：買掛金 500,000円 ／ 貸方：当座預金 500,000円

→ 当座預金の残高： 借方 300,000 ─ 貸方 500,000 ＝ 貸方残 200,000円（マイナス） ```

T字勘定（当座借越発生時）：

`` 当座預金 ───────────────────────── 前期繰越 300,000│小切手振出 500,000 │（貸方残高 200,000） 合計 300,000│合計 500,000 → 貸方残 200,000円 → これが当座借越 ``

決算整理仕訳（当座借越を負債勘定に振替）：

`` 例：期末に当座預金が貸方残高200,000円 借方：当座預金 200,000円 ／ 貸方：当座借越 200,000円 （または「借入金」に振替） ``

翌期首の再振替仕訳：

`` 借方：当座借越 200,000円 ／ 貸方：当座預金 200,000円 ``

貸借対照表での表示：

`` 負債の部 Ⅰ 流動負債 当座借越（または短期借入金）200,000円 ``

試験のキモ

簿記3級 過去問では、以下のパターンが決算整理問題で頻出です。

  1. 当座預金の貸方残高の認識：T字勘定で当座預金が貸方超過→当座借越
  2. 決算整理仕訳：貸方残高を当座借越（または借入金）へ振替
  3. B/Sでの表示：当座借越は負債の流動負債に計上
  4. 翌期首再振替：問題文で「再振替仕訳」が指示される場合あり

混同しやすい用語

  • 当座借越（負債）vs 当座預金（資産）：当座預金がプラス残高なら資産、マイナス残高（借越状態）なら負債として当座借越に振替
  • 当座借越 vs 借入金：どちらも負債。当座借越を「借入金」に振り替えることも多い（問題文に従う）
  • 二勘定制 vs 一勘定制：二勘定制はプラス時は当座預金、マイナス時は当座借越を期中から使う。一勘定制は期中は当座預金1本、決算で振替（3級は一勘定制が標準）

試験対策・関連リンク

簿記3級 過去問・勉強方法・独学・仕訳の観点で「当座預金の残高がマイナス（貸方残）＝当座借越＝負債」という流れを確実に覚えましょう。簿記3級 独学では、T字勘定で当座預金残高を追いながら「貸方が超過したら当座借越に振り替える」感覚を身につけることが決算問題突破のカギです。簿記3級 過去問の決算整理問題には、当座借越の振替仕訳がほぼ毎回含まれています。
