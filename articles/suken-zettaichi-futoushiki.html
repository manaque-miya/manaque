絶対値を含む不等式方程式・不等式数学検定

絶対値を含む不等式とは何か

「|x−1|＜3」「|2x＋1|≧5」のように絶対値記号を含む不等式が絶対値を含む不等式だ。「距離の不等式」として考えると直感的に理解しやすく、|X|＜a ↔ −a＜X＜a（サンドイッチ型）と|X|＞a ↔ X＜−a または X＞a（分割型）の2パターンを区別するのが解法の核心だ。

💡 ポイント: |X|＜a（距離が a 未満）は範囲が中心付近に集まる「サンドイッチ」、|X|＞a（距離が a より大）は範囲が中心から離れる「両端への分岐」。不等号の向きで形が全く変わる点に注意。

2つの基本パターン

パターン1：|X|＜a（a＞0）→ サンドイッチ型

→ −a＜X＜a（1つの連続した範囲）

例: |x−1|＜3
→ −3＜x−1＜3
→ 各辺に＋1 → −2＜x＜4 パターン2：|X|＞a（a＞0）→ 分割型

→ X＜−a または X＞a（2つに分かれる範囲）

例: |2x＋1|≧5
→ 2x＋1≦−5 または 2x＋1≧5
→ 2x≦−6 または 2x≧4
→ x≦−3 または x≧2
型不等式解の形イメージ
サンドイッチX＜a−a＜X＜a中心付近に集まる
分割X＞aX＜−a または X＞a両端に広がる
⚠️ 間違いやすいパターン: 「|X|＜a → X＜a だけ（左側の −a＜X を書き忘れる）」が最頻出の誤答だ。絶対値は左右両方に距離の境界があることを忘れてはならない。また「|X|＞a → −a＜X＜a（サンドイッチと逆に使う）」という完全な符号逆転ミスも多い——覚える際は「＜はサンドイッチ（狭くなる）、＞は分割（広がる）」というイメージで。

ここが試験のキモ ✅

✅ 不等号が「＜」→ サンドイッチ型（−a＜X＜a）
✅ 不等号が「＞」→ 分割型（X＜−a または X＞a）
✅ 符号変換が必要な場合は、変換後に各不等式を解いて統合する

場合分けによる別解法

絶対値の中が 0 になる x の値を基点に場合分けして解く方法も有効だ：

|x−1|＜3 を場合分けで解く：

  • x≧1 のとき：x−1＜3 → x＜4 → 1≦x＜4
  • x＜1 のとき：−(x−1)＜3 → x−1＞−3 → x＞−2 → −2＜x＜1
  • 合わせると：−2＜x＜4（公式型と一致）


🎯 試験対策：絶対値不等式の重要ポイント

数学検定準2級〜2級では「絶対値不等式と一次不等式・二次不等式を組み合わせた連立不等式」が出る。|x−2|＜3 かつ x²－x−6＜0 のような問題では、絶対値不等式の解「−1＜x＜5」と二次不等式の解「−2＜x＜3」の共通範囲「−1＜x＜3」を取る。

2次（記述式）では「絶対値不等式の解を数直線に図示した後、別の不等式の解と重ね合わせて共通範囲を求める」答案構成が評価される。計算だけでなく数直線による視覚的な説明を加えることで、論述の説得力が増す。
