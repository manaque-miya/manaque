FRRとFARとは？

生体認証の精度を測る2つの指標。「本物を弾く率」と「偽物を通す率」のどちらを重視するかで設計が変わる。

🎬 こんなシーンを想像
会社のセキュリティ担当のあなた。指紋認証システムを導入することになった。「精度は高ければいいだろう」と思っていたら、上司から「FRRとFARのバランスを考えろ」と言われた。
→ FRRとFARって何？どっちを下げればいいの？
🔍 FRR と FAR の図解
FRR（本人拒否率）
False Rejection Rate。本物の本人を「別人」と判定してしまう割合。
→ 利便性が下がる（本人が弾かれる）
FAR（他人受入率）
False Acceptance Rate。本物でない他人を「本人」と認証してしまう割合。
→ セキュリティが下がる（偽者が通る）
⚖️ 用途によって重視する指標が違う
⚠️ ひっかけ注意ポイント
FRR と FAR の名前が逆になりやすい
FRR は「Rejection（拒否）」→ 本人を拒む。FAR は「Acceptance（受入）」→ 他人を受け入れる。頭文字の R と A で覚える。
「どちらも低くすればよい」は誤り
FRRを下げようとする（判定を緩くする）とFARが上がる。逆もしかり。必ずトレードオフが発生する。
FRRが高い＝利便性が低い（セキュリティ面は関係なし）
FRRが高いと本人が弾かれる回数が増える＝使いにくい。セキュリティが上がるわけではない。セキュリティはFARで測る。
🧠 覚え方（無理やりゴロ）
FRR＝「本人をリジェクト（拒否）」
F=False / R=Rejection ／ 本人なのに弾かれる悲劇

FAR＝「アカの他人をアクセプト（受入）」
F=False / A=Acceptance ／ 赤の他人が通る恐怖

「F-R-R：本人がリジェクトされて涙（泣）」
