当座借越契約とは何か

当座借越契約（とうざかりこしけいやく）とは、企業が銀行と結ぶ「一定の金額（借越限度額）まで当座預金がマイナスになっても小切手・手形を支払ってもらう」という事前の契約です。「当座借越契約 とは」と検索されるように、簿記3級 試験で当座借越を理解する前提となる概念です。

この契約がなければ、当座預金残高を超える小切手を振り出した時点で「不渡り」となり、企業の信用が失墜します。当座借越契約は資金繰りの安全弁として機能します。

当座借越契約の仕組み

契約の流れ：

``` ① 企業と銀行が「借越限度額500万円」等の当座借越契約を締結 → この時点では仕訳なし（単なる契約なので）

② 当座預金残高を超えて小切手を振り出した場合（実際にマイナス発生） → 当座預金が貸方残高になる（一勘定制の場合） → 決算整理で当座借越勘定に振替

③ 借越限度額の範囲内であれば、銀行は不渡りにせず立替払い ```

契約だけでは仕訳しない：

```

  • ✅ 当座借越契約を締結した → 仕訳なし
  • ✅ 実際に借越状態になった（当座預金がマイナス）→ 決算で仕訳

```

試験のキモ

簿記3級 過去問では、当座借越契約自体は「問題文の前提条件」として登場します。

  1. 契約締結時に仕訳は不要：約束事であり、財産・負債の変動はない
  2. 実際に借越状態になった時（決算整理時）に初めて仕訳：当座借越（負債）として計上
  3. 借越限度額の確認：問題文で「限度額500万円」等と示され、超過しない範囲での処理が前提

混同しやすい用語

  • 当座借越契約 vs 当座借越：契約は事前の約束（仕訳なし）、当座借越は実際にマイナスになった状態（決算整理で仕訳あり）
  • 当座借越契約 vs ローン契約：銀行ローンは実際に借りた時から借入金が発生するが、当座借越契約は実際にマイナスになるまで仕訳が生じない点が異なる

試験対策・関連リンク

簿記3級 過去問・勉強方法・独学・仕訳の核心は「契約時は仕訳なし、実際にマイナスになった（決算）時に仕訳」というタイミングの違いです。問題文で「当座借越契約を結んでいる」という記述は「当座預金がマイナスになった場合は当座借越として処理してください」という指示だと読み取ることが、簿記3級 試験で確実に正答するコツです。
