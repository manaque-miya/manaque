分圧・分流とは何か

分圧（ぶんあつ）とは直列回路において電源電圧が各抵抗に比例配分される現象のことで、分流（ぶんりゅう）とは並列回路において電源電流が各枝路に反比例配分される現象のことです。分圧・分流 とは何かを一言でいえば「直列では電圧が抵抗値の比で分かれ、並列では電流が抵抗値の逆数の比で分かれるという回路の基本法則」です。

佐藤さん（電工見習い・現場新人）が「分流の公式、なんで相手の抵抗を分子に使うんだ？」と首をかしげた。先輩が「抵抗が大きい方が電流をブロックする、だから逆になる」と教えてくれて、やっと腑に落ちた。

「直列に20Ωと30Ωをつないだとき、100Vがどう分かれる？」——20Ωには40V、30Ωには60Vが分かれます（抵抗比2:3で電圧が分圧）。第二種電気工事士 筆記試験では分圧・分流の計算問題が計算分野の中でも特に出題頻度が高く、第二種電気工事士 過去問・技能試験・独学・何時間練習しても慣れるまで混乱しやすい単元です。

分圧・分流の公式と計算例

分圧の公式（直列回路）

直列回路の各抵抗の電圧は、電源電圧 V を各抵抗の比で配分します：

``` V₁ = V × R₁ / (R₁ + R₂) V₂ = V × R₂ / (R₁ + R₂)

例：V=100V, R₁=20Ω, R₂=30Ω V₁ = 100 × 20/50 = 40V V₂ = 100 × 30/50 = 60V ```

分流の公式（並列回路）

並列回路の各枝路電流は、全電流 I を各抵抗の逆数の比で配分します。2枝路では相手の抵抗を使って：

``` I₁ = I × R₂ / (R₁ + R₂) ← 相手の抵抗を分子に I₂ = I × R₁ / (R₁ + R₂) ← 自分の抵抗を分子に（注意）

例：全電流I=5A, R₁=20Ω, R₂=30Ω（並列） I₁（20Ω側）= 5 × 30/50 = 3A I₂（30Ω側）= 5 × 20/50 = 2A 検算: I₁ + I₂ = 3 + 2 = 5A ✓ ```

分流の直感的理解

並列回路では「抵抗が大きい方に電流が少なく流れ、抵抗が小さい方に多く流れる」という直感に一致します。I₁：I₂ = R₂：R₁（逆比）を覚えると公式が自然に理解できます。

ここが試験のキモ

第二種電気工事士 筆記試験で分圧・分流について押さえるべきポイントは3点です。

  1. 分圧は「比例」・分流は「反比例（逆比）」という根本の違い：直列回路では電圧は各抵抗に「比例」して分かれます（大きい抵抗に大きい電圧）。並列回路では電流は各抵抗に「反比例」して分かれます（大きい抵抗に小さい電流）。「分圧＝比例・分流＝反比例」という対比を最初に理解することで、両方の計算公式が自然に導けます。
  1. 分流の公式「相手の抵抗を分子に」は間違えやすい：分流公式 I₁ = I × R₂/(R₁+R₂) は「R₁側の電流を求めるのにR₂を使う」という直感に反する式です。「抵抗の大きい方が電流を少なくブロックする→小さい電流しか流れない→抵抗と電流は反比例→分子に相手の抵抗」という論理を確認してから暗記すると忘れにくくなります。
  1. 分圧を使えばいちいち全電流を計算しなくても電圧が求まる：直列回路で各抵抗の電圧を求める際、「まず全電流I=V/R を計算してから V₁=IR₁」という手順と「分圧公式 V₁=V×R₁/(R₁+R₂) を直接適用」する手順の2通りがあります。後者は計算ステップが1つ少なくなる場合があります。第二種電気工事士 過去問の時間内解法として、状況に応じて速い方を選べる柔軟性を身につけましょう。

混同しやすい用語

  • 分圧（直列）vs 分流（並列）の使い分け：分圧は直列回路専用・分流は並列回路専用。「直列回路に分流を使う」「並列回路に分圧を使う」という誤りが計算問題でよく起きる。問題を見たら「これは直列か並列か」を最初に確認する。
  • 分流公式の分子（I₁のとき R₂ を使う）vs 分圧公式の分子（V₁のとき R₁ を使う）：分圧は自分の抵抗を分子にする（V₁ = V×R₁/(R₁+R₂)）が、分流は相手の抵抗を分子にする（I₁ = I×R₂/(R₁+R₂)）。この非対称が最大の混同ポイント。「分流は逆」と記憶する。
  • 分圧比 vs 電圧降下（絶対値）：分圧比は比率（R₁：R₂ = V₁：V₂）で示し、電圧降下は具体的な電圧値（V₁ = 40V等）で示す。試験問題によって「比率を答えよ」か「電圧値を求めよ」かが異なるため、問題文を慎重に読む。

試験対策・関連リンク

第二種電気工事士 勉強方法として、分圧・分流は「直列＝比例（分圧）・並列＝逆比（分流）」という原則を先に理解し、公式は後から確認するという順序で習得することが定着の近道です。第二種電気工事士 独学では100V・2抵抗の数値で分圧と分流それぞれ10問を繰り返し解き、計算パターンを完全に自動化してください。第二種電気工事士 過去問・技能試験・独学・何時間かけて学ぶかに関わらず、分圧・分流を集中的に解いて短時間で高い得点力を身につけましょう。
