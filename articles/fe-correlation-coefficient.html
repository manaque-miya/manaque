相関係数とは何か

2つの変数の直線的な関係の強さと向きを −1 から +1 の間の値で表す指標が相関係数だ。記号は r で、r = Σ[(xi − μx)(yi − μy)] / (n × σx × σy) と定義される（共分散を両者の標準偏差の積で割った値）。

💡 ポイント: r = +1 → 完全な正の相関（一方が増えれば他方も増える）、r = 0 → 無相関、r = −1 → 完全な負の相関（一方が増えれば他方は減る）。

ECサイトの「広告費と売上の相関係数 0.8」は「広告費が増えると売上が増える傾向が強い」を意味する。ただし「だから広告費を増やせば売上が上がる」という因果関係を断言することはできない。これが「相関と因果は別物」という重要な区別だ。

相関の強さの目安

r の絶対値相関の強さ解釈
0.9 以上非常に強い相関一方からほぼ正確に他方を予測できる
0.7〜0.9強い相関実用的な予測精度
0.4〜0.7中程度の相関傾向はある
0.4 未満弱い相関傾向はほとんど見られない
⚠️ 間違いやすいパターン: 「相関係数 = 0 なら2変数は完全に無関係」は誤り。r = 0 は「直線的な関係がない」ことを意味するだけで、U字型の非線形関係が存在することもある。また、相関≠因果の混同も頻出の引っかけだ。

ここが試験のキモ ✅

✅ r は −1 から +1 の範囲。+1：完全正相関、0：無相関、−1：完全負相関
✅ 相関 ≠ 因果（相関がある ≠ 一方が他方の原因）
✅ r = 0 でも非線形の関係がある場合がある
✅ 散布図で右肩上がり → 正の相関、右肩下がり → 負の相関

相関係数と決定係数

相関係数 r の2乗（r^2）を「決定係数（R^2）」と呼ぶ。r^2 は「回帰直線で説明できるデータの変動の割合」を表す。r = 0.8 なら r^2 = 0.64 で、「目的変数の変動の64%が説明変数で説明できる」と解釈できる。回帰分析とセットで登場する概念として押さえておく。

🎯 試験対策：相関係数の重要ポイント

基本情報試験では「散布図のデータから相関の向きと強さを読み取る」問題と、「相関と因果の混同を指摘する」問題が頻出だ。

散布図問題では、点の並びが「左下から右上に向かう」なら正の相関、「左上から右下に向かう」なら負の相関と即判断できる。点が一直線に近いほど相関が強く（r が ±1 に近い）、広がっているほど弱い（r が 0 に近い）。

「相関≠因果」の引っかけは試験の定番だ。「A と B に正の相関がある場合、Aが Bを引き起こしている」という説明が誤りであることを指摘できればよい。見えない第三の変数（交絡変数）が両者を同時に増加させている可能性も常に存在する。

「基本情報技術者 勉強方法」として、散布図 + 相関係数の問題は科目A の統計・確率分野で必ず出題される。過去問をいくつか解いて「散布図を見て相関係数の範囲を答える」パターンに慣れておくことを勧める。
