連立方程式方程式・不等式数学検定

連立方程式とは何か

2つ以上の方程式を同時に満たすx, yの値を求めるのが連立方程式だ。中学2年で本格的に学ぶが、「2直線の交点を求める」「2つの条件を同時に満たす値を探す」という考え方は高校数学のあらゆる場面に登場する。

💡 ポイント: 連立方程式の解とは、すべての式を同時に満たす値の組（x, y）。グラフでいえば「2直線の交点の座標」に対応する。

2つの解法

加減法（係数を揃えて消去）

両式の係数を調整して足し引きし、一方の文字を消去する。

例：3x＋2y＝8 と 5x－2y＝4 を解く
→ 足すと 8x＝12 → x＝3/2
→ 代入して y＝(8－3×3/2)/2＝7/4

代入法（一方を他方に代入）

一方の式をある文字について解き、他方の式に代入する。

例：y＝2x－1 と 3x＋y＝9 を解く
→ 3x＋(2x－1)＝9 → 5x＝10 → x＝2, y＝3
解法向いているケース
加減法係数が揃えやすい場合
代入法一方が「y＝…」の形の場合
⚠️ 間違いやすいパターン: 加減法で「係数の絶対値が同じ場合、同符号なら引く・異符号なら足す」の判断ミス。2y と 2y が同じ符号で並んでいる場合は引き算して消す。異符号（2y と－2y）なら足して消える。消去の方向を確認してから計算に入ること。

ここが試験のキモ ✅

✅ 加減法：係数の絶対値を揃えてから足し引き
✅ 代入法：「y＝…」の形があれば即座に代入法が有効
✅ 解を求めた後、必ず両方の式に代入して確かめをする

連立方程式の文章題

問題の種類設定方法
2種類の商品の値段購入数×値段の合計が2通りの等式になる
速さと時間の問題往路・復路で速さが違う場合
濃度の混合食塩の量と全体の量の2式を立てる

🎯 試験対策：連立方程式の重要ポイント

数学検定3級（中学レベル）では2元1次連立方程式が1次・2次ともに頻出だ。係数に分数が含まれる場合（例：x/2＋y/3＝1）は両辺に最小公倍数を掛けて整数係数に直してから解く。計算量が増えるほどミスが増えるため、係数の整数化を最初に行う習慣が重要。

また文章題では「何をx、何をyに置くか」を明示してから式を立てる。「速さの問題では単位を km/h か m/分か統一する」「人数・個数は整数なので分数の解が出たら立式を見直す」という確認習慣を身につけること。
