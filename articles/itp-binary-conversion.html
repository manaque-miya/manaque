2進数の基数変換とは？

「基数」＝数を表すために使う数字の種類の数。10進数↔2進数の変換は、コンピュータの数の世界への入口。

🎬 こんなシーンを想像
プログラムのバグを調査中。デバッグツールに「0b1010」と表示されている。「これって10なの？それとも2なの？」と迷ってしまった。2進数とわかれば変換するだけ。
…「0bから始まる数＝2進数」。変換ルールを知れば一瞬で解読できる！
🔢 2進数の「位の重み」を図解
🔄 変換の2大手順

【A】2進数 → 10進数（位の重みで足し算）

例：1011（2進数）を10進数に
1×8 + 0×4 + 1×2 + 1×1
＝ 8 + 0 + 2 + 1 ＝ 11

【B】10進数 → 2進数（2で割り続ける）

① 10進数の数値を2で割る
割り切れる間ずっと2で割る。余りが0か1になる。
▼
② 余りを記録する
割るたびに余り（0か1）をメモしていく。
▼
③ 余りを下から上へ読む
最後の余りが最上位ビット（MSB）。下から上へ並べた並びが答え。
例：13（10進数）を2進数に
13÷2＝6 余り1　← ④
6÷2＝3 余り0　← ③
3÷2＝1 余り1　← ②
1÷2＝0 余り1　← ①（ここで終了）
下から読む → 1101
⚠️ ひっかけ注意ポイント
余りを上から読んでしまう
2で割り続けたとき、余りは「下から上へ」読むのが正解。上から読むと桁が逆になって全く別の数になる。
位の重みを右から2⁰と数え忘れる
右端が2⁰（＝1）、左に行くほど2倍。「右端は1」を固定して考える。
0のビットを無視する
1010 の場合、0の桁は「0×4」「0×1」→どちらも0。足し算に含めなくていいが桁の位置はズレてはいけない。
判断のコツ
「2進数→10進数」は位の重みで足し算。「10進数→2進数」は2で割り算して余りを下から読む。方向を間違えない。
🧠 覚え方（無理やりゴロ）
「にしん→じゅっ：重みで足す」
2進数→10進数：右から1・2・4・8…で重みをかけて足す

「じゅっ→にしん：2で割って下から読む」
10進数→2進数：÷2し続けて余りを逆順に並べる
