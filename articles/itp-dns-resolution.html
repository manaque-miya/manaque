DNSの名前解決とは？

URLを入力したら、なぜそのページが表示されるのか。裏で動く「住所の翻訳サービス」の仕組み。

🎬 こんなシーンを想像
ブラウザに 「www.example.com」 と打つと、一瞬でページが表示される。
でも実は、コンピューターはURLのままでは通信できない。裏で IPアドレス（数字の住所） に変換されている。
…その変換をやっているのが DNS の名前解決！
🗺️ 名前解決の仕組み
🔄 名前解決の流れ（詳細）
① ブラウザに URL を入力
「www.example.com」のように人間が読めるドメイン名を入力する。コンピューター同士の通信には数字のIPアドレスが必要なので、そのまま使えない。
▼
② DNS サーバーに問い合わせ
「このドメイン名のIPアドレスを教えて」と DNS サーバーへ質問を送る。DNS サーバーはドメイン名とIPアドレスの対応表（名前帳）を持っている。
▼
③ IP アドレスが返ってくる
DNS サーバーが「www.example.com → 203.0.113.10 です」と数字のIPアドレスを教えてくれる。これが名前解決の完了。
▼
④ IP アドレスで通信開始
取得したIPアドレスを使って、目的のWebサーバーに直接アクセスする。ここからようやくページのデータが届く。
⚠️ ひっかけ注意ポイント
DNSとDHCPを混同しやすい
DHCPは「デバイスにIPアドレスを自動で割り当てる」仕組み。DNSは「ドメイン名をIPアドレスに変換する」仕組み。役割がまったく違う。
「名前解決」はURL→IPアドレスの一方向
「名前解決＝ドメイン名 → IPアドレス」の変換。逆にIPアドレス → ドメイン名を調べることは「逆引き」という別の処理。
DNSサーバーは「自分でページを持っていない」
DNSサーバーはあくまで「住所を教えてくれる電話帳係」。Webページのデータを持つのはWebサーバー。役割を混同しないこと。
🧠 覚え方（無理やりゴロ）
DNS ＝ 電話の「なまえ」を「すばやく」変換
D＝でんわちょう（名前帳）／N＝なまえ（ドメイン名）／S＝すばやく→IPアドレスに変換

「名前を言ったら、番号を教えてくれる係」＝DNS
URLを言う → IPアドレスが返ってくる → 接続する、の3ステップ！
