経過勘定とは何か

経過勘定（けいかかんじょう）とは、期間損益計算を正確に行うために当期と次期の収益・費用を切り分ける4種類の決算整理勘定の総称だ。「経過勘定 とは」「経過勘定 4種類 簿記3級」「前払費用 未払費用 前受収益 未収収益 違い」と検索されるほど、簿記3級 試験の第3問・決算整理仕訳で欠かせない重要概念だ。

簿記は「発生主義」という原則に基づいており、現金の収支時点ではなく「発生した時点」で収益・費用を計上する。しかし家賃・利息・保険料などは、期間をまたいで支払・受取が行われることが多い。こうした「時間のずれ」を正しく処理し、当期分だけを当期の損益に計上するために経過勘定が使われる。

経過勘定は4種類あり、「見越し（まだやっていないことを計上）」と「繰延べ（やりすぎた分を翌期に回す）」に分類できる。

経過勘定4種の仕訳パターン

4種類の比較表と代表仕訳：

``` 【前払費用（資産）＝費用の繰延べ】 払ったが次期分 → 決算で：（借）前払費用 ／（貸）保険料（費用）

【前受収益（負債）＝収益の繰延べ】 受け取ったが次期分 → 決算で：（借）受取家賃（収益）／（貸）前受収益

【未払費用（負債）＝費用の見越し】 当期分だが未払い → 決算で：（借）支払利息（費用）／（貸）未払費用

【未収収益（資産）＝収益の見越し】 当期分だが未受領 → 決算で：（借）未収収益 ／（貸）受取利息（収益） ```

マトリックスで整理：

`` 費用側 収益側 ────────────────────────────────────────── 繰延べ │前払費用（資産） │前受収益（負債） 見越し │未払費用（負債） │未収収益（資産） ────────────────────────────────────────── ``

翌期首の再振替仕訳（全4種共通ルール）：

`` 前払費用→（借）保険料 ／（貸）前払費用 前受収益→（借）前受収益 ／（貸）受取家賃 未払費用→（借）未払費用 ／（貸）支払利息 未収収益→（借）受取利息 ／（貸）未収収益 （4種とも「決算仕訳の逆仕訳」） ``

試験のキモ

簿記3級 過去問の第3問（決算整理）では、経過勘定4種のどれかが必ず出題される。

  1. 問題文の状況から4種類のどれかを判断：「当期発生・未払」→未払費用、「次期分・前払済み」→前払費用、など
  2. 月割計算で金額を算出：元本×年利率×月数/12、または総額×対応月数/総月数
  3. 決算仕訳と再振替仕訳の両方を書ける：翌期首の逆仕訳も問われることがある
  4. 資産か負債かを正確に判断：前払費用・未収収益→資産、前受収益・未払費用→負債

最もよくある失点は「4種類を混同して借貸を逆に書く」ことだ。マトリックス（繰延べ/見越し × 費用/収益）を暗記してから解答するのが最も確実だ。試験直前にこの4マスを書ける状態にしておこう。

経過勘定と紛らわしい勘定との比較

経過勘定よく混同される勘定見分け方
前払費用前払金前払費用＝期間費用の繰延べ、前払金＝商品の手付
前受収益前受金前受収益＝期間収益の繰延べ、前受金＝商品の手付
未払費用未払金未払費用＝経過勘定、未払金＝固定資産等の購入代金
未収収益未収入金未収収益＝経過勘定、未収入金＝固定資産等の売却代金

試験対策・関連リンク
