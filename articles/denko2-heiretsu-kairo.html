並列回路とは何か

並列回路（へいれつかいろ）とは、2つ以上の電気素子（抵抗など）を同じ端子間に並べて接続し、各素子に共通の電圧がかかる回路のことです。並列回路 とは何かを一言でいえば「複数の抵抗が同じ電圧の点から点へ並んでつながっており、各素子に同じ電圧がかかるが流れる電流は素子ごとに異なる回路」です。

佐藤さん（電工見習い・現場新人）が現場でコンセント回路の図面を見て「全部100Vかかってる、だから並列だな」とひとり納得した。電圧が共通という原則が腹落ちした瞬間だった。

「並列につなぐと電球が明るいのはなぜ？」——並列接続では各電球に電源電圧がそのままかかるため、直列よりも電球一つあたりの電圧・電流が大きくなり明るく光ります。また合成抵抗が小さくなるため全電流が増加します。第二種電気工事士 筆記試験では並列回路の合成抵抗計算・各枝路の電流計算が毎回出題され、第二種電気工事士 過去問・技能試験・独学・何時間の学習でも直列回路と並んで必出の計算テーマです。

並列回路の計算公式

並列回路の3つの基本原則

項目公式説明
電圧V = V₁ = V₂ = …すべての抵抗に同じ電圧がかかる
合成抵抗1/R = 1/R₁ + 1/R₂ + …逆数の和の逆数が合成抵抗
各枝路電流I₁ = V / R₁各電流は電圧÷各抵抗値
電流の総和I = I₁ + I₂ + …各枝路電流の合計＝全電流

2抵抗並列の計算（積÷和の公式）

2抵抗の並列回路では次の簡便公式が使えます： `` R合成 = (R₁ × R₂) / (R₁ + R₂) ``

計算例（2抵抗並列）

``` 電源電圧 V = 100V R₁ = 20Ω、R₂ = 30Ω を並列接続

合成抵抗 R = (20 × 30) / (20 + 30) = 600 / 50 = 12Ω 全電流 I = 100 / 12 ≈ 8.33A

R₁の電流 I₁ = 100 / 20 = 5A R₂の電流 I₂ = 100 / 30 ≈ 3.33A 検算: I₁ + I₂ = 5 + 3.33 = 8.33A ✓ ```

同じ値の抵抗を並列接続した場合

同値 R の抵抗を n 本並列に接続した場合： `` 合成抵抗 = R / n （例：20Ωを2本並列→20/2 = 10Ω） ``

ここが試験のキモ

第二種電気工事士 筆記試験で並列回路について押さえるべきポイントは3点です。

  1. 「並列回路の電圧はすべて等しい」という大原則：並列接続された全抵抗の両端には同じ電圧がかかります。「電圧が共通」という並列の基本原則から、各枝路電流は I = V/R で求められます。直列の「電流が共通」と対比して覚えることで、どちらの回路かを判断した瞬間に正しい公式に切り替えられます。
  1. 合成抵抗は「積÷和」（2抵抗の場合）を使うと計算が速い：2抵抗の並列合成抵抗を逆数公式（1/R = 1/R₁ + 1/R₂）で解くと分数計算が発生して手間がかかります。「積÷和」の公式（R = R₁R₂/(R₁+R₂)）を使えば計算時間を大幅に短縮できます。第二種電気工事士 過去問では2抵抗並列が最頻出パターンなので、この公式を反射的に使えるよう練習してください。
  1. 並列合成抵抗は元の抵抗より必ず小さい：並列接続すると電流経路が増えるため、合成抵抗は各抵抗の最小値よりも必ず小さくなります。「20Ωと30Ωを並列にしたら12Ω（両方より小さい）」という結果の方向性を確認する習慣をつけると、計算ミスを即座に検出できます。第二種電気工事士 独学での自己採点に有効なチェック方法です。

混同しやすい用語

  • 並列回路 vs 直列回路の合成抵抗計算：並列は逆数の和（1/R = 1/R₁+1/R₂）で合成抵抗が小さくなる、直列は加算（R = R₁+R₂）で合成抵抗が大きくなる。「直列→大きくなる・並列→小さくなる」という方向性が試験の最大の引っかけポイント。計算前に必ず「直列か並列か」を確認する。
  • 並列電流の分流 vs 直列電圧の分圧：並列回路では電流が各枝路に「分流」（抵抗に反比例して電流が分かれる）し、直列回路では電圧が各抵抗に「分圧」（抵抗に比例して電圧が分かれる）する。この対比を理解すると、分流・分圧の計算問題を統一した視点で解けるようになる。
  • 並列接続の抵抗 vs 並列接続のコンデンサ：抵抗を並列接続すると合成抵抗が減少するが、コンデンサを並列接続すると合成容量は増加する（C = C₁ + C₂）。コンデンサの並列は足し算、直列は逆数になり、抵抗とは逆の関係になる点が試験で混乱のもとになりやすい。

試験対策・関連リンク

第二種電気工事士 勉強方法として、並列回路は「電圧が共通→各電流は V/R→合成抵抗は積÷和」という3ステップの手順で100V・2抵抗の計算を繰り返すことが最も効率的です。第二種電気工事士 独学では直列と並列の問題を交互に解いて「どちらの公式を使うか」の判断を自動化することが重要です。第二種電気工事士 過去問・技能試験・独学・何時間取り組むかに関わらず、2抵抗並列の積÷和と枝路電流の手順を完全にマスターして演習を積みましょう。
