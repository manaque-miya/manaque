凹凸とは何か

グラフの「曲がり方の向き」が凹凸だ。2階微分 f''(x) の符号によって判定する——f''(x) ＞ 0 なら下に凸（U字型、谷型）、f''(x) ＜ 0 なら上に凸（∩型、山型）だ。1階微分 f'(x) で判定する「増減」とは全く別の情報であり、グラフの完全な概形を描くには両方の情報が必要だ。

💡 ポイント: なぜ f'' で凹凸がわかるのか。f''(x) ＞ 0 は「f'(x) が増加中」を意味する——つまり傾き（接線の傾き）が増加していくと、グラフは「下を向いた笑顔」のU字型になる。逆に f''(x) ＜ 0 は「f'(x) が減少中」なので傾きが下がっていき「∩型（しかめ面型）」になる。

中村さん（中学3年生・数学検定3級受験）が「上に凸って山型なの、下に凸って谷型なの？」と混乱したとき、先生は「凸の字の出っ張りが向いている方向で覚えて」と言い、中村さんはU字をノートに大書してすぐに腑に落ちた。増減と凹凸は別の表が必要なことも、ここで初めて理解できた。

凹凸の判定と例

f''(x) の符号と凹凸の対応:

f''(x) の符号グラフの形和名視覚的イメージ
f''(x) ＞ 0U字（谷型）下に凸笑顔の口
f''(x) ＜ 0∩型（山型）上に凸しかめ面
f''(x) ＝ 0 で符号変化凹凸が切り替わる変曲点S字の中央

例題: f(x) ＝ x³ − 6x の凹凸を調べよ。

  • f'(x) ＝ 3x² − 6
  • f''(x) ＝ 6x
  • f''(x) ＝ 0 → x ＝ 0

2次関数との比較:

2次関数 f(x) ＝ ax² では f''(x) ＝ 2a（定数）であり、グラフ全体が一様に下に凸（a ＞ 0）または上に凸（a ＜ 0）——凹凸の切り替わりがない。3次以上の関数で初めて「凹凸が変わる（変曲点が存在する）」可能性が生まれる。

⚠️ 間違いやすいパターン: 「上に凸」「下に凸」の言葉が直感と逆に感じる受験生が多い。「下に凸（U字）」は「谷のように下を向いて凸が出ている」というイメージで、実際には底が下にあるU型だ。「上に凸（∩型）」は「山のように上を向いて凸が出ている」イメージ。「凸の字の突き出している方向と混同する」のが典型ミス——「上に凸 ＝ 山型 ＝ ∩」「下に凸 ＝ 谷型 ＝ U」と図で確認する習慣をつけること。

ここが試験のキモ ✅

  • ✅ 凹凸は f''(x)（2階微分）で判定——f' の増減とは別の情報
  • ✅ f''(x) ＞ 0 → 下に凸（U字）、f''(x) ＜ 0 → 上に凸（∩型）
  • ✅ 凹凸が切り替わる点が変曲点——f'' ＝ 0 かつ符号変化が必要

増減と凹凸の独立性

増減と凹凸は独立した情報だ。例えば「増加しながら上に凸」（f' ＞ 0, f'' ＜ 0）という状態は、「加速を緩めながら上昇する曲線」を表す——傾きは正だが傾きが減少していく状態だ。

増減凹凸接線の傾きの変化例
増加 ↗下に凸傾きが増加急加速中の上昇
増加 ↗上に凸傾きが減少減速しながら上昇
減少 ↘下に凸傾きが増加（マイナスから0へ）底に向かって収束
減少 ↘上に凸傾きが減少（より急な下降）急降下

🎯 試験対策：凹凸の重要ポイント

数学検定準1級では「グラフの概形を描け」という問題の一部として凹凸の確認が必須になる。独学での勉強では「増減表」に加えて「凹凸表」を作る練習を確実にすること——増減表だけ書いてグラフを描く習慣が付いていると凹凸情報が欠落した不完全な答案になる。

数学検定 過去問・勉強方法・独学で学ぶ際は、f''(x) ＝ 0 の解で区間を分割し「∪ / ∩」と変曲点の座標を答案に明記する凹凸表の練習を繰り返すことが準1級の高得点への最短ルートだ。
