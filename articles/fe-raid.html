RAIDとは何か

複数のディスクドライブを組み合わせて 1 つの論理ドライブとして扱い、「冗長性（故障耐性）」や「性能向上」を実現する技術が RAID（Redundant Array of Independent Disks）だ。レベル（0、1、5、6、10）によって仕組みと特性が大きく異なり、それぞれが試験の頻出テーマになっている。

💡 ポイント: RAID は「冗長性と速度のトレードオフ」をレベルで選択する技術。RAID0 は速度のみ・冗長性ゼロ、RAID1 は冗長性のみ、RAID5 はバランス型というのが大枠だ。

「基本情報技術者 勉強方法」では各 RAID レベルの特性を表で比較して覚えるのが最も効率的だ。

ここが試験のキモ ✅

✅ RAID0: 速度最大・冗長性ゼロ（1台故障で全データ消失）
✅ RAID1: 冗長性◎（ミラー）・容量効率50%
✅ RAID5: バランス型・N台なら(N-1)/N の容量効率・1台故障OK
✅ RAID6: 2台故障OK・容量効率(N-2)/N
✅ RAID10: RAID1のミラーペアをRAID0でストライプ・高速&高冗長・容量効率50%

RAID5のパリティ計算

RAID5 では「データブロック同士の XOR（排他的論理和）がパリティ」になる。4 台構成でディスク A に「1100」、ディスク B に「1010」、ディスク C に「0110」のデータがある場合、パリティ P = A XOR B XOR C = 「0000」となり、ディスク D に書かれる。ディスク B が壊れたとき A XOR C XOR P を計算してディスク B の内容を復元できる。

🎯 試験対策：RAIDの重要ポイント

「基本情報技術者 過去問」での頻出はレベルの識別問題と容量効率の計算だ。「4 台のディスクで RAID5 を構成したとき、使用可能な容量は全体の何%か？」なら (4-1)/4 = 75% と即答する。

実務文脈として「高可用性が求められるデータベースサーバには RAID10」「コスト重視でバランスが良いのは RAID5」「バックアップには RAID6（再構築中の 2 台同時故障リスクに対応）」という知識も記述問題で使える。

「基本情報技術者 独学」では RAID0/1/5 の 3 レベルを完璧に、RAID6/10 を概要レベルで覚えれば試験得点には十分だ。
