恒等式数と式（高校）数学検定

恒等式とは何か

含まれる文字にどんな値を代入しても両辺が等しい等式が恒等式だ。x²＋2x＋1＝(x＋1)² はすべての実数 x で成立する——これが恒等式の典型例だ。特定の値を代入したときだけ成立する「方程式」とは本質的に異なり、「常に等しい」という性質が恒等式を定義する。

💡 ポイント: 恒等式と方程式の区別は数学検定でも頻出テーマだ。方程式は「解（特定の値）」を持つが、恒等式は「すべての値で成立する」。恒等式かどうかを確かめるには「両辺を展開・整理して同じ式になるか」確認するか、複数の値を代入して全て成立するかを確認する。

恒等式と方程式の比較

比較項目方程式恒等式
成立する x特定の値のみ（「解」）すべての実数 x
例x²＋2x＋1＝0（x＝−1 のみ）x²＋2x＋1＝(x＋1)²（すべての x）
「解く」のかはい（解を求める）いいえ（成立条件を確認する）
記号の使い方＝（等号）≡（恒等号、教科書によっては＝）
係数比較法の活用:

ax²＋bx＋c＝2x²＋3x－1 が x についての恒等式となるとき a, b, c を求めよ。

恒等式なら「両辺の同じ次数の係数は等しい」——この原理が係数比較法だ。

次数左辺の係数右辺の係数結論
x²の係数a2a＝2
x の係数b3b＝3
定数項c−1c＝−1
⚠️ 間違いやすいパターン: 「方程式として解いて x の値を出そうとする」誤りが最頻出だ。恒等式の問題は「x の値を求める」のではなく「係数 a, b, c を求める」問題だ。問題文に「すべての x で成り立つ」「恒等式となるように」と書かれていたら、方程式として解くのではなく係数比較法または数値代入法を使う。

ここが試験のキモ ✅

✅ 恒等式は「全ての x で成立する等式」——方程式（特定の x のみ）とは別物
✅ 係数比較法：両辺を展開して同じ次数の係数を等しく置く
✅ 数値代入法：特定の x の値（0, 1, −1 など）を代入して係数を特定する

数値代入法との使い分け

係数比較法と並ぶ恒等式の解法が数値代入法だ。x＝0, 1, −1 など計算が楽な値を代入して係数の連立方程式を作り解く。

例：a(x－1)(x－2)＋b(x)(x－2)＋c(x)(x－1)＝x²＋1 が恒等式

  • x＝0 を代入：a×(−1)×(−2)＝0＋1 → 2a＝1 → a＝1/2
  • x＝1 を代入：0＋b×1×(−1)＋0＝1＋1 → −b＝2 → b＝−2
  • x＝2 を代入：0＋0＋c×2×1＝4＋1 → 2c＝5 → c＝5/2
係数比較法が「展開して整理」、数値代入法が「代入して個別に求める」——問題の形に応じて使い分ける。

🎯 試験対策：恒等式の重要ポイント

数学検定2級〜準1級では「恒等式の係数を求める」問題が出題される。係数比較法は「両辺を丁寧に展開してから各次数の係数を比べる」という手順が確実だが、数値代入法の方が計算量が少ない場面もある。2次（記述式）では「x＝○を代入すると」「両辺の x² の係数を比べると」のように根拠を明示しながら計算する答案が高評価につながる。

部分分数分解（例：2/(x(x＋1))＝A/x＋B/(x＋1) となる A, B を求める）は恒等式の応用として準1級以上で頻出だ。両辺に x(x＋1) を掛けて整理すると「2＝A(x＋1)＋Bx が x について恒等式」という形になり、係数比較または数値代入で A＝2, B＝−2 が求まる流れを繰り返し練習すること。
