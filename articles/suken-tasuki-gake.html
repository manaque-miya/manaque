たすき掛けとは何か

「x²の係数が1でない二次式（ax²＋bx＋c, a≠1）を因数分解する技法」がたすき掛けだ。通常の「足してb、掛けてc」では対応できない式を、係数 a と c を分解して斜め交差（たすき）の積の和が b になる組み合わせを探すことで解ける。

中村さん（中学3年生・数学検定3級受験）が 2x²＋5x＋3 を前に「係数が2だから普通の因数分解できない…」と手が止まった。「たすきを使えばいい、aとcの組み合わせを表に書いて試すんだよ」とヒントをもらい、(2,1)×(3,1)の交差和が5になると分かった瞬間に解法の仕組みが腑に落ちた。

💡 ポイント: たすき掛けは「ax²＋bx＋c を (px＋q)(rx＋s) の形に分解する方法」。p×r＝a、q×s＝c を満たしつつ、ps＋qr＝b（たすきの積の和）になる組み合わせを探す。

たすき掛けの手順

例題：2x²＋5x＋3 を因数分解する

ステップ1：a＝2 を分解：2＝2×1 または 2＝1×2

ステップ2：c＝3 を分解：3＝3×1 または 3＝1×3

ステップ3：たすきの積の和が b＝5 になるか確認：

左上右上左下右下たすきの和結果
23112×1＋1×3＝5✅

→ (2x＋3)(x＋1) が答え

ステップ4：確認のため展開する (2x＋3)(x＋1)＝2x²＋2x＋3x＋3＝2x²＋5x＋3 ✅

⚠️ 間違いやすいパターン: 「たすきの積の和がbになっているか確認せず書いてしまう」ミスが頻発。また a や c がマイナスの場合、符号のパターンが増えて見落としやすい。必ず展開して確かめる習慣をつけること。

ここが試験のキモ ✅

  • ✅ x²の係数が 1 のときは通常の因数分解（たすき掛け不要）
  • ✅ a≠1 のとき：a と c の因数分解パターンを列挙してたすきを確認する
  • ✅ マイナス符号がある場合は符号の組み合わせも体系的に試す

たすき掛けが使われる場面

式の形必要な処理
x²＋bx＋c通常の因数分解（たすき不要）
2x²＋5x＋3たすき掛け必須
6x²＋7x＋2たすき掛け（複数パターン試行）
3x²－5x－2たすき掛け（マイナス符号あり）

🎯 試験対策：たすき掛けの重要ポイント

数学検定準2級〜2級の1次では「ax²型の因数分解」が出題される。たすき掛けの手順を体系化するには「a と c の因数分解パターンを紙に書き出してから、たすきの和が b になるものを探す」手順を身体化することが重要だ。数学検定 過去問・勉強方法・独学で取り組む際は、a＝2〜6 程度の問題を中心に組み合わせ探しのスピードを上げる練習が効果的だ。

特に 6x²＋7x＋2 のように a＝6（＝6×1 または 2×3 または 3×2）と c＝2（＝2×1 または 1×2）で複数パターンある場合、試行錯誤が必要だ。「まず整数係数の小さいパターンから試す」という戦略と、展開による検算の習慣で答案の信頼性を高めること。
