スタック（Stack）とは？

データを「積み上げて・上から取り出す」構造。最後に入れたものが最初に出てくる＝LIFO（後入れ先出し）。

こんなシーンを想像
食器棚に重ねた皿。洗い終わった皿を上から積んでいく。取り出すときは上の皿から使う。
つまり一番最後に積んだ皿Cが、最初に手に取られる。
これがスタックの「後入れ先出し（LIFO）」！A, B, C と積んでpopしたら C → B → A の順に出る。
スタックの動作図解

スタック（LIFO）

  • 後入れ先出し
  • Last In, First Out
  • push / pop で操作
  • 例：皿の積み重ね・Ctrl+Z

キュー（FIFO）

  • 先入れ先出し
  • First In, First Out
  • enqueue / dequeue で操作
  • 例：銀行の行列・プリントキュー
操作の仕組みと試験頻出パターン
push A → push B → push C（積む）
スタックの中身は底からA→B→C（TOP）。pushは常にTOPに積み上がる。ブラウザの「戻る」ボタンやCtrl+Zがこの仕組みを使っている。
▼
1回目 pop → C（最後に入れたもの）が出る
popは常にTOP（一番上）から取り出す。残りはA・B。TOPはB。
▼
2回目 pop → B、3回目 pop → A（最初に入れたものが最後）
最終的な出力順：C → B → A。入力の逆順になるのがLIFOの特徴。試験では「push A, B, C の後、3回popすると？」の形で出る。
ひっかけ注意ポイント
スタック vs キュー — 最もよく混同される
キューは「先入れ先出し（FIFO：First In First Out）」。スタックはLIFO（後入れ先出し）。L＝Last（後が先）・F＝First（先が先）で区別する。
「先に入れたものが先に出る」はキューであってスタックではない
スタックは後入れ先出し。「先に入れたものが先に出る」のはキュー（FIFO）。試験では「LIFO」「FIFO」の対比で出やすい。
push/pop の「どこから」に注意
スタックはTOP（一番上）からしかアクセスできない。配列のように途中へのアクセスはできない。キューの操作名はenqueue/dequeueで別物。
覚え方（無理やりゴロ）
LIFO は「ライバルが後（ろ）から来た！」
後から来たやつ（Last In）が先に飛び出す（First Out）＝後入れ先出し

FIFOと区別するには：L＝Last（後が先）・F＝First（先が先）
頭文字LとFで「LastかFirstか」が決まる
