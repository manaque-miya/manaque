SQLの DMLとは？

データベースのデータを「操作」するSQL命令の総称。SELECT（検索）・INSERT（追加）・UPDATE（更新）・DELETE（削除）の4本柱。

🎬 こんなシーンを想像
ECサイトのシステム担当になったあなた。「商品テーブルから価格1000円以上を取得したい」「新商品を追加したい」「在庫数を更新したい」…これらをSQLで書くとき、全部 DML を使う。
…DML の「M」って何の略？どんな命令が含まれる？
📊 DMLの4命令
SELECT
検索・取得
条件を指定してデータを取り出す。最もよく使う命令。
SELECT * FROM 商品 WHERE 価格 > 100
INSERT
追加・挿入
新しいデータ（行）をテーブルに追加する。
INSERT INTO 商品 VALUES(...)
UPDATE
更新・変更
既存データの値を書き換える。条件で対象を絞る。
UPDATE 商品 SET 価格=150 WHERE ID=1
DELETE
削除
条件に合う行をテーブルから削除する。
DELETE FROM 商品 WHERE ID=3
📂 SQL命令の3分類
DML（データ操作）
SELECT
INSERT
UPDATE
DELETE
DDL（定義）
CREATE
ALTER
DROP
TRUNCATE
DCL（制御）
GRANT
REVOKE
COMMIT
ROLLBACK

DDL＝テーブルの構造を操作（作る・消す）。DML＝テーブルの中身（データ）を操作。

⚠️ ひっかけ注意ポイント
DDLと混同しやすい
CREATE・DROP・ALTER はテーブルの構造定義を変える DDL。
SELECT・INSERT などデータ自体を動かすのが DML。
TRUNCATEはDMLではない
全行削除の TRUNCATE は DDL の仲間。DELETEと似ているが分類が違う点に注意。
判断のコツ
「テーブルのデータ（中身）を扱う命令」→ DML
「テーブルの構造（設計）を変える命令」→ DDL
🧠 覚え方（無理やりゴロ）
DMLの4命令は「捜し（SELECT）・入れ（INSERT）・更新（UPDATE）・消す（DELETE）」
略すと 捜・入・更・消 → 「捜索隊、入って更地に消えた」

DDL（構造）とDML（中身）
DDL = Define（定義・設計図）
DML = Manipulate（データを動かす）
