原始関数とは何か

微分すると f(x) になる関数 F(x) を原始関数（または不定積分の主要部分）という。F'(x) ＝ f(x) を満たす F(x) が原始関数だ。例えば f(x) ＝ 2x の原始関数は x² だが、x² ＋ 5 も x² − 3 も微分すると 2x になるため、原始関数は無数に存在する。この「定数項の不確定性」を積分定数 C で表現したものが不定積分 F(x) ＋ C だ。

💡 ポイント: 原始関数と不定積分の違いは「＋C があるかないか」だ。原始関数は「F'(x) ＝ f(x) を満たす F(x) のうちの1つ」であり、不定積分 ∫f(x)dx は「F(x) ＋ C（全ての原始関数の集合）」を表す。一般に「原始関数を求める ＝ 不定積分を計算する」と同じ意味で使われることが多い。

中村さん（中学3年生・数学検定3級受験）が「不定積分って＋Cを書かないとダメなの？」と首をかしげたとき、先生は「微分すると消える定数が無限にあるから、全部まとめて C と書くんだよ」と説明した。中村さんは「じゃあ定積分では C が消えるんだ」と続きを自分で言い当てて、先生が「そのとおり！」と笑顔で答えた。

原始関数と不定積分・定積分の関係

原始関数が「無数にある」理由:

関数微分すると結論
x²2xf(x) ＝ 2x の原始関数
x² ＋ 12xf(x) ＝ 2x の原始関数
x² ＋ 52xf(x) ＝ 2x の原始関数
x² ＋ C（任意の C）2x全て f(x) ＝ 2x の原始関数

→ f(x) ＝ 2x の不定積分 ＝ x² ＋ C（C は任意定数）

微積分の基本定理との関係:

原始関数 F(x) を1つ決めると、定積分の計算は F(b) − F(a) で行える。定積分の計算では F(x) ＋ C の C がどんな値でも消えるため（F(b)＋C − (F(a)＋C) ＝ F(b)−F(a)）、原始関数は「どれか1つを選べばよい」。

例題: f(x) ＝ x² の原始関数を求め、∫(1→3) x² dx を計算せよ。

  1. 原始関数の1つ：F(x) ＝ x³/3
  2. 定積分：F(3) − F(1) ＝ 27/3 − 1/3 ＝ 26/3

⚠️ 間違いやすいパターン: 「原始関数はただ1つ」という誤解がある——原始関数は定数項の違いで無数に存在する。「不定積分は ＋C があるのに、なぜ定積分の計算で特定の原始関数（C ＝ 0 の場合）だけ使えるの？」という疑問もよく出るが、答えは「F(b) − F(a) の計算で C が消えるから、どの原始関数を使っても答えは同じになる」だ。

ここが試験のキモ ✅

  • ✅ 原始関数は「微分すると f(x) になる関数 F(x)」——無数に存在する
  • ✅ 不定積分 ∫f(x)dx ＝ F(x) ＋ C（C は積分定数）——全ての原始関数を表す
  • ✅ 定積分では F(b) − F(a) の計算で C が消える——任意の原始関数で計算できる

微積分の基本定理（まとめ）

概念定義・式性質
原始関数 F(x)F'(x) ＝ f(x)無数に存在（定数項の差）
不定積分 ∫f(x)dxF(x) ＋ C全ての原始関数の集合
定積分 ∫(a→b) f(x)dxF(b) − F(a)一意の数値（C が消える）

🎯 試験対策：原始関数の重要ポイント

数学検定2級〜準1級では、「不定積分を求めよ」という問題で原始関数の概念が問われる。採点では「答えに ＋C が付いているか」が重要な評価点であり、＋C を忘れると減点対象になる。

数学検定 過去問・勉強方法・独学で学ぶ際は「∫xⁿ dx ＝ xⁿ⁺¹/(n＋1) ＋ C」などの公式を「微分すると元に戻ることを確認して理解する」アプローチで練習することが、公式の単純暗記よりも長期的な定着を早める最善策だ。
