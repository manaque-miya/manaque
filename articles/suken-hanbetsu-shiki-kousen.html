二次関数と判別式とは何か

二次関数 y ＝ ax² ＋ bx ＋ c のグラフが x 軸と交わる点の個数（0・1・2 個）を決定するのが判別式 D ＝ b² − 4ac だ。「二次方程式 ax² ＋ bx ＋ c ＝ 0 の実数解の個数」と「放物線が x 軸と交わる個数」は完全に一致する——これが「グラフ」と「方程式」を橋渡しする判別式の本質だ。

💡 ポイント: D ＝ b² − 4ac の3つの場合：D ＞ 0 なら2点で交わる（異なる2つの実数解）、D ＝ 0 なら1点で接する（重解、x 軸に接線を引く形）、D ＜ 0 なら交わらない（実数解なし）。「D ＝ 0 は解がない」という誤解が多いが、D ＝ 0 は重解が1つ存在する（2つの解が一致した状態）であり「解がない」のは D ＜ 0 だ。

判別式の3パターンと活用

判別式と x 軸の位置関係:

D の値二次方程式の実数解グラフと x 軸の関係グラフのイメージ
D ＞ 0異なる2実数解 α, β2点で交わるx 軸を貫く
D ＝ 0重解 α ＝ −b/(2a)1点で接する（x 軸に接する）x 軸に触れる
D ＜ 0実数解なし（虚数解2つ）交わらないx 軸の上または下に浮く

例題: y ＝ x² − 4x ＋ k が x 軸と接する（1点で交わる）条件を求めよ。

D ＝ (−4)² − 4 × 1 × k ＝ 16 − 4k ＝ 0 → k ＝ 4

「常に x 軸より上（または下）」の条件:

a ＞ 0 の二次関数が「常に x 軸より上」（任意の x に対して f(x) ＞ 0）であるための条件は D ＜ 0 だ——グラフが x 軸と交わらず全体的に上にあることを意味する。これは「二次不等式の解が全ての実数」という状況と同じだ。

条件D の符号意味
a ＞ 0 かつ D ＜ 0D ＜ 0f(x) ＞ 0 が常に成立（全ての x で）
a ＞ 0 かつ D ＝ 0D ＝ 0f(x) ≧ 0 が常に成立（等号あり）
a ＞ 0 かつ D ＞ 0D ＞ 0f(x) ＜ 0 となる x が存在する

⚠️ 間違いやすいパターン: 「D ＝ 0 だから解がない」という誤解が最多だ——D ＝ 0 は「重解が1つある」であり、「解がない ＝ D ＜ 0」と明確に区別すること。次に多いミスは「判別式 D ＝ b² − 4ac の計算ミス」——b が負の場合に符号処理を間違えやすい。例えば b ＝ −4 なら b² ＝ 16（マイナスが消える）。また「接する ＝ D ＝ 0」だが「通る ＝ D ≧ 0（2点交わり含む）または D ＝ 0（接する）」という言葉の区別も問われる。

ここが試験のキモ ✅

  • ✅ D ＝ b² − 4ac：D ＞ 0（2交点）、D ＝ 0（接する＝重解）、D ＜ 0（交わらない）
  • ✅ 「D ＝ 0 ＝ 解がない」は誤り——D ＝ 0 は重解1つ、D ＜ 0 が解なし
  • ✅ a ＞ 0 かつ D ＜ 0 ⟺ f(x) ＞ 0 が常に成立

判別式を使った文字定数の条件問題

「k の値によって二次方程式の実数解の個数が変わる」という問題パターンでは、「D ＞ 0 の範囲、D ＝ 0 の値、D ＜ 0 の範囲」を k の不等式で表すことが問われる。D を k の式として整理し、D の符号を k で場合分けする——この手順を答案にきちんと書くことが記述式での満点答案の条件だ。

🎯 試験対策：二次関数と判別式の重要ポイント

数学検定2級〜準1級の頻出問題は「接する条件・交わらない条件を求めよ」「常に正（負）となる条件を求めよ」の2パターンだ。前者は D ＝ 0、後者は D ＜ 0（a ＞ 0 の場合）という判断を即座に行えるように、数学検定 過去問・勉強方法・独学で反復練習することが最善策だ。

特に「常に f(x) ≧ 0」（等号含む）の条件は D ≦ 0 ではなく「a ＞ 0 かつ D ≦ 0」であることに注意——a ＜ 0 なら下に凸ではなく上に凸になるため、D の符号だけでは不十分で a の符号の確認が必須だ。
