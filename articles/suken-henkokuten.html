変曲点微分積分（高校）数学検定

変曲点とは何か

グラフの「曲がり方（凹凸）」が切り替わる点が変曲点だ。条件は「f''(x) ＝ 0 かつ前後で f'' の符号が変化する」点だ。上に凸（∩型）から下に凸（U型）に切り替わる瞬間、または逆の切り替わり——そのグラフの「折れ目」にあたる点が変曲点だ。

💡 ポイント: f''(x) ＝ 0 は変曲点の「必要条件」だが「十分条件ではない」。f''(0) ＝ 0 でも、前後で f'' の符号が変化しなければ変曲点ではない（例：y ＝ x⁴ の x ＝ 0 は変曲点でなく極小点）。「f'' ＝ 0 だけで変曲点と断言してはいけない」が試験の核心だ。

変曲点の判定手順

例題: f(x) ＝ x³ の変曲点を求めよ。
ステップ計算結果
① f'(x) を求める微分f'(x) ＝ 3x²
② f''(x) を求めるもう1回微分f''(x) ＝ 6x
③ f''(x) ＝ 0 を解く6x ＝ 0x ＝ 0
④ 前後の符号変化を確認x ＜ 0: f''＜0（上に凸）、x ＞ 0: f''＞0（下に凸）符号変化 あり
⑤ 変曲点と判定f(0) ＝ 0変曲点は (0, 0)
凹凸と変曲点のまとめ:
f''(x) の符号グラフの形呼び方
f''(x) ＞ 0U型（谷型）下に凸
f''(x) ＜ 0∩型（山型）上に凸
f''(x) が 0 を挟んで符号変化凹凸が切り替わる変曲点
⚠️ 間違いやすいパターン: 「f''(x) ＝ 0 ⟹ 変曲点」と直結させるのは誤りだ。y ＝ x⁴ では f''(x) ＝ 12x²、f''(0) ＝ 0 だが x ＝ 0 の前後でどちらも f'' ＞ 0（符号変化なし）——変曲点ではなく極小点だ。また「変曲点で f' ＝ 0」は必須ではない——f' ≠ 0 でも変曲点は存在する（f(x) ＝ x³ の x ＝ 0 では f'(0) ＝ 0 だが、これは例外的なケース）。

ここが試験のキモ ✅

✅ 変曲点の条件は「f'' ＝ 0 かつ 前後で f'' の符号変化」——どちらも必要
✅ f'' ＝ 0 だけでは変曲点と確定できない——符号変化の確認が必須
✅ 変曲点はグラフの「凹凸の切り替わり点」——極値とは別の概念

極値と変曲点の比較

比較項目極値（極大・極小）変曲点
条件f' ＝ 0 かつ f' の符号変化f'' ＝ 0 かつ f'' の符号変化
使う微分1階微分 f'2階微分 f''
判定対象増減（増加↔減少）凹凸（上に凸↔下に凸）
グラフ上の意味山頂・谷底曲がり方の切り替わり
「極値 ＝ 1階微分で判定」「変曲点 ＝ 2階微分で判定」——使う微分の次数が異なる点が整理の核心だ。

🎯 試験対策：変曲点の重要ポイント

数学検定準1級の1次・2次では「グラフの概形を描け」という問題で変曲点の把握が必要になる。概形を描く標準手順は「① f'(x) で増減表 → ② f''(x) で凹凸表 → ③ 変曲点を求める → ④ グラフを描く」の4ステップだ。特に凹凸表では「f''(x) の符号が変わる x の値で区間を分割し、各区間で ＋/− を記入する」という作業が必要——f''(x) ＝ 0 の解を求めて終わりにせず、符号変化の確認まで完了させること。

2次（記述式）で変曲点を求める問題では「x ＝ ○○ の前後で f''(x) の符号が○→○に変化するから、変曲点は (○○, f(○○)) である」という記述を答案に含めることが求められる。f'' ＝ 0 の解だけを書いて終わりにせず、符号変化の確認を答案に明示することが完全答案の条件だ。
