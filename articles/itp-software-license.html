ソフトウェアライセンス管理とは何か

ソフトウェアライセンス管理とは、企業や組織が使用するソフトウェアのライセンス（使用権）を適切に把握・管理する業務だ。ライセンス数より多くのPCにインストールすると著作権侵害（不正コピー）となり、逆にライセンスを過剰取得するとコスト無駄が生じる。BSA（ビジネス ソフトウェア アライアンス）の調査では2022年に世界の企業ソフトウェアの約20%が未ライセンス状態と報告されている。

💡 ポイント: ライセンス管理の目標は「必要な分だけ、正規に、過不足なく」—不足はコンプライアンスリスク、過剰はコスト無駄という二方向のリスクを同時に管理することだ。

ライセンス種類の比較

ライセンス種類内容代表例
個人ライセンス特定の個人1名が使用Adobe Creative Cloud個人版
端末ライセンス特定のPC・機器に紐づく一部のOS・組み込みソフト
ユーザーライセンス（CAL）接続ユーザー数に応じた課金Windows Server CAL
サイトライセンス特定の施設・拠点内で無制限利用大学や企業向けボリュームライセンス
同時使用ライセンス同時アクセス可能な最大ユーザー数を管理データベースソフト
OSSライセンス無償利用可能だが条件ありGPL・MIT・Apache

⚠️ 間違いやすいパターン: OSSだからといって「完全に自由に使える」わけではない。GPL（GNU General Public License）は改変・配布時にソースコードの公開義務が生じる「コピーレフト条項」があり、商用製品に組み込む際は注意が必要だ。

SAMとISO/IEC 19770

ソフトウェア資産管理（SAM：Software Asset Management）は、ライセンス管理を体系的に行うためのフレームワークだ。ISO/IEC 19770はSAMの国際規格であり、ソフトウェア資産の棚卸し・ライセンス照合・コンプライアンス維持の手順を規定している。Windows環境ではMicrosoft System Center Configuration Manager（SCCM）などのツールでインストール状況を自動収集しライセンス管理と照合する。

ここが試験のキモ

  • ✅ ライセンス違反は著作権法違反。発覚時は損害賠償・刑事罰の対象
  • ✅ OSSにも種類によってコピーレフト（GPL）や帰属表示（MIT・Apache）などの条件がある
  • ✅ SAM（ソフトウェア資産管理）が体系的なライセンス管理のフレームワーク

混同しやすい用語との違い

用語特徴
ソフトウェアライセンスソフトウェアの使用権を規定する契約
IT資産管理ハードウェア・ソフトウェア両方を対象とした資産管理全般
OSS（オープンソース）ソースコードが公開されたソフトウェア。ライセンス条件は種類による
プロプライエタリソフトウェア使用・複製・改変を制限する閉鎖型ライセンスのソフトウェア

🎯 試験対策：ソフトウェアライセンス管理の重要ポイント

試験ではOSSライセンスの種類と特徴が頻出だ。GPLは「改変版の再配布時にソースコード公開義務あり」、MITとApacheは「帰属表示のみで商用利用可能」という違いを押さえる。「GPLソフトを自社製品に組み込んで販売する場合、自社のソースコード公開義務が生じることがある」という問題が典型的だ。

ボリュームライセンスやサイトライセンスの概念も出題される。学校・企業が特定ソフトを一括購入して複数台に導入する契約形態がサイトライセンスであり、1ライセンスを複数台にコピーするのとは法的に異なることを理解しておく。
