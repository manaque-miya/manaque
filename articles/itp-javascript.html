JavaScriptとは？

Webブラウザの中で動く「動きをつけるための言語」。クリックしたら変化・ポップアップ・バリデーションなど、ページをインタラクティブにする。

🎬 こんなシーンを想像
ネットショッピングで「カートに入れる」ボタンを押した瞬間、ページが更新されずに「1品追加されました！」とポップアップが出る。フォームで電話番号を入力中に「数字のみ入力してください」とリアルタイムで警告が出る。
…これら全部、ブラウザの中でJavaScriptが動いている。
🖥️ JavaScriptが動く場所（クライアントサイド）

本来JavaScriptは「ブラウザ（クライアント）の中で動く言語」。HTMLがページの骨格、CSSが見た目、JavaScriptが動きを担当する。

⚖️ 混同しやすい言語との比較

JavaScript

ブラウザで動く動的スクリプト。型定義が緩い。HTMLに組み込んでそのまま動く。

Java

名前は似てるが別物。コンパイルが必要な静的型言語。業務システム・Android開発に多用。

TypeScript

JavaScriptに型を追加した言語。大規模開発向け。最終的にJSに変換される。

⚙️ ブラウザでJavaScriptが動く流れ
① HTMLファイルをブラウザが受け取る
Webサーバからブラウザにページのデータが届く。HTMLの中に<script>タグでJSが埋め込まれている。
▼
② ブラウザのJSエンジンがコードを実行
ブラウザ内蔵のJavaScriptエンジン（ChromeはV8）がコードを解釈・実行。コンパイル不要でそのまま動く。
▼
③ DOM操作でページを動的に変える
JSはDOM（Document Object Model）を通じてHTMLの要素を書き換える。ページ再読み込みなしにコンテンツを変更できる。
⚠️ ひっかけ注意ポイント
「JavaとJavaScriptは同じ」は完全に誤り
名前が似ているだけで開発元・用途・動作方式がすべて異なる別の言語。Javaはコンパイル型・オブジェクト指向の汎用言語。JavaScriptはインタープリタ型のスクリプト言語。
「サーバサイドでは動かない」は誤り
Node.jsの登場でサーバサイドでも動く。ただしITパスポートの文脈では「主にブラウザ（クライアントサイド）で動く」と覚えておく。
コンパイルが必要かどうか
JavaScriptはインタープリタ型（コンパイル不要・そのまま実行）。Javaはコンパイルが必要（ソースコード→バイトコード→実行）。動作方式の違いも問われる。
🧠 覚え方（無理やりゴロ）
「Java＝島、JavaScript＝島のスクリプト（台本）」は偶然の名前の一致！
JavaScript＝ジャバがつくだけのネーミング。別物と割り切る。

ゴロ：「JS＝ページに"じ（動）さ（作）"す（する）」
ページを「動作させる」言語＝JavaScript。HTMLが骨・CSSが皮・JSが筋肉（動かす）。
