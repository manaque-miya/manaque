2階微分とは何か

関数 f(x) を2回続けて微分した関数が2階微分（または二次導関数）だ。記号は f''(x)（ダッシュ2個）または d²f/dx² で表す。物理的には「位置の2階微分 ＝ 加速度」というように、変化量の変化量を表す概念でもある。

f''(x) ＝ [f'(x)]'（f'(x) をさらに x で微分する）

💡 ポイント: 2階微分 f''(x) は3つの使い方がある。①凹凸の判定（f''＞0：下に凸、f''＜0：上に凸）、②変曲点の検出（f'' ＝ 0 かつ符号変化）、③極値の2次判定（f'(a) ＝ 0 のとき、f''(a) ＞ 0 なら極小、f''(a) ＜ 0 なら極大）——これら3役を理解することが2階微分の核心だ。

中村さん（中学3年生・数学検定3級受験）が「f'とf''って何が違うの？」と聞いたとき、先生は「f'は上り下りの方向、f''はその方向が急になるか緩むかを教えてくれる」と答えた。中村さんは「加速度みたいな感じか」とつぶやき、3役の使い分けをメモに整理し始めた。

2階微分の計算と活用

例題: f(x) ＝ x⁴ − 4x³ ＋ 2 の 2 階微分を求め、凹凸を調べよ。

ステップ計算結果
① 1階微分f'(x) を計算f'(x) ＝ 4x³ − 12x²
② 2階微分f'(x) をさらに微分f''(x) ＝ 12x² − 24x ＝ 12x(x − 2)
③ f''(x) ＝ 0 を解く12x(x−2) ＝ 0x ＝ 0 または x ＝ 2
④ 符号を確認x ＜ 0: ＋, 0＜x＜2: −, x＞2: ＋変曲点：x ＝ 0, x ＝ 2

極値の2次判定（f'' による判定）:

f'(a) ＝ 0 の点 x ＝ a が極値かどうかを f'' で判定できる：

f''(a) の値判定理由
f''(a) ＞ 0x ＝ a は極小その点で下に凸 → 谷底
f''(a) ＜ 0x ＝ a は極大その点で上に凸 → 山頂
f''(a) ＝ 0判定不可増減表（1階微分）で再確認

⚠️ 間違いやすいパターン: 「2階微分 f''(x)」と「関数を2乗した [f(x)]²」は全く別物だ。f''(x) はダッシュ2個（微分を2回行う操作）で、[f(x)]² は元の関数の2乗——記号の見た目が似ているだけで内容は完全に異なる。もう一つのミスは「f''(a) ＝ 0 なら変曲点と断言する」こと——f'' ＝ 0 は変曲点の必要条件に過ぎず、前後の符号変化の確認が必要だ。

ここが試験のキモ ✅

  • ✅ 2階微分は「f'(x) をさらに微分」——f''(x) ＝ [f'(x)]'
  • ✅ f''(x) の3役：①凹凸判定、②変曲点の検出、③極値の2次判定
  • ✅ f''(a) ＝ 0 だけで変曲点と断言不可——前後の符号変化が必要

2階微分の記法

記法読み方使用場面
f''(x)エフ・ダッシュ・ダッシュ一般的な教科書・参考書
y''ワイ・ダッシュ・ダッシュy ＝ f(x) の場合
d²f/dx²ディー・ツー・エフ・ディー・エックスの2乗物理・工学・大学数学
d²y/dx²同上y ＝ f(x) の場合

🎯 試験対策：2階微分の重要ポイント

数学検定準1級の2次（記述式）では「グラフの概形を描く問題」の中で2階微分を使う凹凸表の作成が必要だ。解答手順として「f''(x) を求める → f''(x) ＝ 0 の解を求める → 前後の符号を確認して凹凸表を作成 → 変曲点の座標を求める」というステップを答案に丁寧に書き出すことが求められる。

数学検定 過去問・勉強方法・独学で対策する際は「f'(a) ＝ 0 の点が極値かどうかを2次判定で確認する」問題も出るため、f''(a) が 0 になった場合に「2次判定法が使えない」と注記して増減表に切り替える姿勢を示せる答案が高得点につながる。
