判別式方程式・不等式数学検定

判別式とは何か

二次方程式の解が「2つか・1つか・0つか」を解そのものを求めずに判定する値が判別式だ。二次方程式 ax²＋bx＋c＝0 の解の公式の√の中身「b²－4ac」がこれにあたり、D（または Δ）で表す。D の符号を見るだけで解の個数と性質がわかる、非常に効率的なツールだ。

💡 ポイント: 判別式 D＝b²－4ac。D＞0 → 異なる2実数解、D＝0 → 重解（解は1個）、D＜0 → 実数解なし（虚数解のみ）。「解の中身より解の個数だけ知りたい」場面で使う。

D の符号と解の関係

D の値解の種類グラフとの関係
D＞0異なる2実数解放物線がx軸と2点で交わる
D＝0重解（x＝－b/2a）放物線がx軸と接する
D＜0実数解なし放物線がx軸と交わらない
例題1：x²－4x＋5＝0 の解の個数を判定する

→ D＝(－4)²－4×1×5＝16－20＝－4
→ D＜0 → 実数解なし

例題2：x²－6x＋9＝0 の解の種類を判定する

→ D＝(－6)²－4×1×9＝36－36＝0
→ D＝0 → 重解（x＝3）

⚠️ 間違いやすいパターン: 「b²の計算でb がマイナスでも2乗だから必ず正」になることを忘れるケースが多い。b＝－5 のとき b²＝25（プラス）。また「D＝b²＋4ac」と符号を逆に覚えてしまうケース——正しくは必ず「引き算（b²マイナス4ac）」。

ここが試験のキモ ✅

✅ D＝b²－4ac（必ず引き算）——「プラス4ac」と間違えない
✅ b がマイナスでも b² は正——符号を間違えずに計算する
✅ D の符号（正・0・負）で解の個数と種類を正確に述べる

判別式の応用

判別式は二次方程式だけでなく、二次関数・円と直線の問題でも活躍する：

応用場面使い方
二次関数のx軸との交点D の符号で「2点交差・接する・離れる」
円と直線の位置関係連立して得た二次方程式の D で判定
「解が実数になるkの条件」D≧0 の不等式を k について解く
応用例：x²＋2kx＋k＋2＝0 が実数解を持つ条件

→ D＝(2k)²－4(k＋2)≧0
→ 4k²－4k－8≧0
→ k²－k－2≧0
→ (k－2)(k＋1)≧0
→ k≦－1 または k≧2

🎯 試験対策：判別式の重要ポイント

数学検定準2級〜2級では「パラメータ k を含む二次方程式が実数解を持つ（または重解を持つ）ための k の条件」問題が頻出だ。解法の流れは「判別式 D を k の式で表す → D≧0（または D＝0）の不等式を立てる → k について解く → 数直線上で範囲を確認する」の4段階。

2次（記述式）では「D の計算過程」と「不等式の解法過程」を両方記述する必要がある。D＝… の計算を式で示し、整理後の不等式の解（数直線も添えると加点される）を明示する習慣をつけること。また「二次関数と直線の接線条件（D＝0）」も頻出テーマとして独立した対策が必要だ。
