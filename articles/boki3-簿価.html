簿価とは何か

簿価（ぼか）とは、固定資産の取得原価から減価償却累計額を差し引いた帳簿上の現在価額のことだ。「簿価 とは」「簿価 計算 簿記3級」「簿価 時価 違い」と検索されるほど、簿記3級 試験の第1問（固定資産売却の仕訳）・第3問（決算整理）で頻出する重要概念だ。正式名称は「帳簿価額（ちょうぼかがく）」だが、試験でも「簿価」という略称が使われる。

簿価は「取得時の価格（取得原価）から、今まで何年か使った分の償却額（減価償却累計額）を差し引いた、現時点での帳簿上の価値」だ。市場で実際に売買される「時価（市場価値）」とは異なる点に注意が必要だ。

固定資産を売却するとき、売却価格と簿価を比較することで「固定資産売却益（儲かった）」または「固定資産売却損（損した）」が確定する。このため簿価の正確な計算が、固定資産売却仕訳の正解への第一歩となる。

簿価の計算・仕訳パターン

簿価の基本計算：

``` 簿価＝取得原価 − 減価償却累計額

例：取得原価100万円の備品、3年間使用、毎年20万円償却 減価償却累計額＝20万×3年＝60万円 簿価＝100万 − 60万＝40万円 ```

売却時の損益計算：

``` 簿価 > 売却額 → 固定資産売却損（費用） 簿価 < 売却額 → 固定資産売却益（収益） 簿価 = 売却額 → 損益ゼロ

例：簿価40万円の備品を50万円で売却 売却益＝50万 − 40万＝10万円（固定資産売却益） ```

固定資産売却の仕訳（間接法・簿価40万・売却額50万）：

`` （借）現金 500,000 減価償却累計額 600,000 ／（貸）備品 1,000,000 固定資産売却益 100,000 ``

T字勘定での確認：

``` 備品（資産） ───────────────────────── 取得原価 1,000,000│売却時消去 1,000,000

減価償却累計額（資産控除） ───────────────────────── 売却時消去 600,000│3年間累計 600,000 （売却時に借方で消す） ```

試験のキモ

簿記3級 過去問の第1問では、固定資産売却の仕訳問題で簿価の計算が必ず必要になる。

  1. 簿価を計算する順序：取得原価を確認→累計償却額を確認（年額×年数）→差し引いて簿価を算出
  2. 売却額と簿価を比較：売却額 > 簿価なら売却益（貸方）、売却額 < 簿価なら売却損（借方）
  3. 間接法の仕訳構造：取得原価・減価償却累計額・売却額・損益の4要素を同時に処理する
  4. 期中売却の場合：売却月までの当期分の月割償却費も計上してから簿価を更新する

最もよくある失点は「取得原価と売却額だけを比べて損益を計算してしまう（累計額を忘れる）」ことだ。必ず「取得原価−累計額＝簿価」→「売却額−簿価＝損益」という2段階で計算する習慣をつけよう。

関連する概念との比較

概念内容計算式
取得原価購入時の総コスト購入代価＋付随費用
減価償却累計額これまでの合計償却額年間償却費×経過年数
簿価（帳簿価額）現時点の帳簿上の価額取得原価−累計額
時価（市場価値）市場での実際の売買価格市場で決まる（帳簿と無関係）
  • 簿価 vs 時価：簿価は帳簿上の計算値、時価は市場の実勢価格。売却損益は「売却額（時価）−簿価」で計算
  • 簿価 vs 取得原価：簿価は「今の価値（減った後）」、取得原価は「買った時の価値（減る前）」

試験対策・関連リンク

簿記3級 仕訳 覚え方として「簿価＝取得原価−減価償却累計額＝帳簿上の今の価値」という計算式を最初に頭に入れる。固定資産売却の仕訳では借方と貸方の合計が一致するかを最後に検算する習慣をつけると計算ミスを防げる。簿記3級 独学では固定資産売却の仕訳を「①簿価計算→②売却額と比較→③損益を確定→④仕訳の4要素を書く」という手順で練習すると、本番でも迷わず処理できる。簿記3級 過去問・勉強方法・独学・仕訳の面から見ても「取得原価○○円、減価償却累計額○○円、売却額○○円で売却した」という問題が典型なので、3要素から即座に簿価と損益を計算できるよう準備しよう。
