APIとは

API（Application Programming Interface）とは、ソフトウェア同士が互いに機能を使い合うための「接続口」や「規約」のことです。「Interface（インターフェース）」は「接続部分」を意味します。

💡 APIは「レストランのメニュー」のようなもの。お客さん（アプリ）はメニュー（API）を見てキッチン（システム）に注文するだけで、料理の作り方を知る必要はありません。

APIの仕組み

あるシステムがAPIを公開すると、他のシステムやアプリがそのAPIを使って機能を呼び出せます。

  • ① クライアント（アプリ）がAPIにリクエストを送る
  • ② APIがシステムの機能を実行する
  • ③ APIがレスポンス（結果）を返す

REST APIとは

Web上で最も広く使われるAPI設計の原則がREST（Representational State Transfer）です。HTTPプロトコルを使ってデータのやり取りを行います。

  • HTTP メソッドを使う（GET：取得、POST：作成、PUT：更新、DELETE：削除）
  • データ形式はJSON（またはXML）が一般的
  • URLで操作対象を指定する
❌ よくある誤解：APIは「プログラマーだけのもの」ではありません。スマホアプリ・WebサービスのほぼすべてがAPIを使って機能しています。

重要ポイントの整理

✅ APIは「ソフトウェア同士の接続口（インターフェース）」。機能を公開して他のシステムから呼び出せるようにする仕組みです。
  • API = アプリケーション間の接続・連携の仕組み
  • Web APIを使うことで他サービスの機能を自分のアプリに組み込める
  • REST API = HTTP を使った最もポピュラーなWeb API設計

APIエコノミーとセキュリティ

APIエコノミー：外部にAPIを公開することでエコシステムを形成するビジネスモデル。地図API（Google Maps）・決済API（Stripe）・SNS API（Twitter/X）が代表例。APIセキュリティ：認証（APIキー・OAuth2.0・JWT）・レート制限（過剰アクセス防止）・入力値検証（インジェクション攻撃対策）・HTTPS通信。APIゲートウェイ：複数APIへのリクエストを一元管理・認証・ルーティング・ログ収集する仕組み。

🎯 試験対策：APIの重要ポイント

APIの本質は「決められた形式で情報をやり取りするための窓口」です。ITパスポート試験では、APIの概念と代表的な活用例を理解することが求められます。

REST APIは現代のWebサービスで最も広く使われる形式で、URLで操作対象を指定し、HTTPメソッド（GET/POST/PUT/DELETE）で操作内容を表します。例えばGET /users/123は「ユーザーID123の情報を取得」を意味します。このシンプルな設計思想が普及の理由です。

試験で覚えるべき重要事項は「APIキー」の概念です。APIキーはAPIを利用する権限を証明する文字列で、不正利用防止のために管理が必要です。公開されたAPIキーは悪用される危険があるため、セキュリティ上の注意が必要です。
