ファイル拡張子とは？

ファイル名の末尾「.txt」「.exe」の部分。ファイルの種類をOSやアプリに伝える"名札"。

🎬 こんなシーンを想像
メールに添付された「invoice.exe」。見た目は請求書っぽいが、.exe はプログラムファイル。開いたら最後、マルウェアが起動した…！
→ 拡張子を知らないと、危険なファイルを踏む。
📄 ファイル名の構造

OSやアプリは拡張子を見て「どのアプリで開くか」を自動判断する。.docx ならWord、.jpg なら画像ビューアで開く。

.jpg / .png
画像ファイル
.docx / .xlsx
Office文書
.mp4 / .mov
動画ファイル
.exe / .bat
実行ファイル⚠️
.zip / .tar
圧縮ファイル
.txt / .csv
テキスト系
🔐 セキュリティと拡張子

Windowsは初期設定で拡張子を非表示にする。そのため「invoice.pdf.exe」が「invoice.pdf」に見えてしまう。これを悪用したマルウェアが多数存在する。

⚠️ ひっかけ注意ポイント
拡張子を変えてもファイルの中身は変わらない
「.jpg」→「.txt」に名前を変えても、中のデータは画像のまま。拡張子はあくまで「名札」であり、中身を変換するものではない。
.pdf は安全とは言い切れない
PDFにはスクリプトを埋め込める。「.pdf だから安全」は誤り。不審なPDFは開かないことが原則。
MIMEタイプと混同しやすい
MIMEタイプ（例：image/jpeg）はネットワーク通信でファイル種別を伝える仕組み。拡張子と概念は似ているが別物。メールやHTTPで使われるのはMIMEタイプ。
🧠 覚え方（無理やりゴロ）
拡張子はファイルの"職業名札"！
.jpg ＝画家、.exe ＝プログラマー、.txt ＝ライター

.exe は危険人物（エグゼクティブ＝実行者）
exe ＝ execute（実行）→ プログラムを起動する → マルウェアの温床
