合成抵抗とは何か

合成抵抗（ごうせいていこう）とは、複数の抵抗を直列・並列・組み合わせで接続したときに、その回路全体を1つの等価抵抗に置き換えたときの抵抗値のことです。合成抵抗 とは何かを一言でいえば「複数の抵抗が組み合わさった回路の『見かけ上の抵抗値』で、この値と電源電圧からオームの法則で全電流が求まる」です。

佐藤さん（電工見習い・現場新人）が初めて直並列混合回路の問題に挑んだとき、「並列を先に合成して、あとで直列に足す」という手順を先輩に教わり、紙に2ステップを書き出したら一発で解けた。

「20Ωと30Ωを直列にすると何Ωになる？並列だと？」——直列なら50Ω、並列なら12Ωです。この2つの計算方法の違いが第二種電気工事士 筆記試験の計算問題で最も多く問われるテーマの一つです。第二種電気工事士 過去問・技能試験・独学・何時間かけても必ず習得すべき核心スキルです。

合成抵抗の計算公式まとめ

直列接続の合成抵抗

``` R = R₁ + R₂ + R₃ + …（単純加算）

例：10Ω + 20Ω + 30Ω = 60Ω ```

並列接続の合成抵抗

``` 1/R = 1/R₁ + 1/R₂ + … （逆数の和）

【2抵抗の場合の便利公式（積÷和）】 R = (R₁ × R₂) / (R₁ + R₂)

例：20Ωと30Ωの並列 R = (20 × 30) / (20 + 30) = 600/50 = 12Ω ```

直並列混合回路の計算手順

直列と並列が混在する回路は、並列部分を先に合成→次に直列部分を加算する手順で解きます。

``` 例：R₁=10Ω（直列）+ R₂=20Ω・R₃=30Ω（並列）

Step1: 並列部分の合成 R₂₃ = (20×30)/(20+30) = 12Ω

Step2: 全体の合成（直列加算） R合成 = R₁ + R₂₃ = 10 + 12 = 22Ω

Step3: 全電流（V=100Vの場合） I = 100/22 ≈ 4.55A ```

同じ抵抗 n 本の場合の簡便計算

`` 直列：R × n（n倍になる） 並列：R / n（n分の1になる） ``

ここが試験のキモ

第二種電気工事士 筆記試験で合成抵抗について押さえるべきポイントは3点です。

  1. 直列は「加算」・並列は「積÷和」を瞬時に使い分ける：合成抵抗の計算で最も重要なのは「直列か並列か」の判断と、それに対応する公式の使い分けです。直列は単純加算、並列（2本）は積÷和という公式セットを反射的に使えるようにすることが、第二種電気工事士 過去問の計算問題を時間内に解くための必須条件です。
  1. 直並列混合回路は「並列を先に合成→直列で加算」の手順：複合回路の計算で最も多く問われるのは直並列混合パターンです。手順を「並列→直列」と固定して覚えることで、どんな複合回路でも機械的に解けるようになります。第二種電気工事士 独学では同じ手順を繰り返し練習して計算パターンを身体化することが大切です。
  1. 並列合成抵抗は「最小値より小さくなる」という検算法：並列接続した合成抵抗は、必ず接続した抵抗の中で最も小さい値よりも小さくなります。計算結果が「元の抵抗の最小値よりも大きい」場合は計算ミスです。第二種電気工事士 過去問で計算した後にこの事実でセルフチェックする習慣をつけると、ケアレスミスを大幅に減らせます。

混同しやすい用語

  • 直列の合成抵抗 vs 並列の合成抵抗：直列は加算で大きくなる、並列は積÷和で小さくなる。「直列→大・並列→小」という方向性が最重要の区別点。公式そのものより、この方向性の感覚を先に身につけると間違いが減る。
  • 合成抵抗の計算 vs 合成静電容量の計算：抵抗と逆の関係にあるのがコンデンサ。抵抗の直列（加算）はコンデンサでは逆数の和（合成容量が減る）、抵抗の並列（逆数の和）はコンデンサでは加算（合成容量が増える）になる。第二種電気工事士 過去問でコンデンサの合成容量問題が出たとき、抵抗と逆であることを思い出すこと。
  • 合成抵抗 vs 合成インピーダンス：抵抗（純抵抗）を合成した値が合成抵抗、抵抗・コイル（インダクタンス）・コンデンサを含む交流回路の等価インピーダンスが合成インピーダンス（Z = √(R²+X²)）。直流回路では合成抵抗のみ、交流回路ではインピーダンスで考える。

試験対策・関連リンク

第二種電気工事士 勉強方法として、合成抵抗は「直列＝加算（大きくなる）・並列2本＝積÷和（小さくなる）・直並列混合＝並列先に合成→直列で加算」という3パターンをそれぞれ5問以上解いて習熟することが合格への王道です。第二種電気工事士 独学では計算した後に「並列の合成は元の最小値より小さいか」を確認するセルフチェックを習慣化してください。第二種電気工事士 過去問・技能試験・独学・何時間の学習計画でも合成抵抗は確実な得点源として習得しましょう。
