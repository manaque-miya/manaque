当座預金出納帳とは何か

当座預金出納帳（とうざよきんすいとうちょう）とは、当座預金の入金と出金（小切手振出等）を日付順に詳細記録する補助記入帳だ。「当座預金出納帳 とは」「当座預金出納帳 書き方」と検索されるほど、簿記3級 試験の第2問で出題される補助帳簿の重要項目だ。

企業の当座預金口座は、複数の小切手が毎日振り出され、売掛金の入金も頻繁にある。銀行の通帳だけでは「どの取引のための振出か」が分かりにくいため、社内でも当座預金出納帳を使って詳細を記録する。特徴的な欄として「小切手番号」欄があり、振り出した小切手を番号で管理できる。

当座預金出納帳の構造と記入方法

当座預金出納帳のフォーマット：

`` 日付 │ 摘要 │小切手番号│ 預入 │ 引出 │ 残高 ─────┼───────────────┼──────────┼───────────┼───────────┼────────── 6/1 │ 前月繰越 │ │ │ │ 300,000 6/5 │ 売掛金入金 │ │ 150,000 │ │ 450,000 6/10 │ 買掛金支払 │ No.101 │ │ 200,000 │ 250,000 6/15 │ 仕入支払 │ No.102 │ │ 100,000 │ 150,000 6/20 │ 売掛金入金 │ │ 80,000 │ │ 230,000 6/30 │ 月次合計 │ │ 230,000 │ 300,000 │ 230,000 ``

記入のポイント：

  1. 預入欄：当座預金への入金（売掛金回収・現金預入等）
  2. 引出欄：小切手振出による支払（買掛金・仕入等）
  3. 残高欄：前残高 ＋ 預入 − 引出 で毎行更新
  4. 小切手番号欄：振り出した小切手の番号を記入（管理上の目安）

当座借越が発生した場合（残高がマイナスになる）：

`` 例：6/25の残高が150,000円のとき、200,000円の小切手を振り出した 6/25 │ 仕入支払 │ No.103 │ │ 200,000 │ △50,000 （残高欄に△マイナス表示 → 当座借越発生） ``

T字勘定との対応：

`` 当座預金 ───────────────────────── 前月残高 300,000│買掛金（小切手）200,000 売掛金 150,000│仕入（小切手） 100,000 売掛金 80,000│ 合計 530,000│合計 300,000 → 残高230,000 ``

試験のキモ

簿記3級 過去問の第2問では、当座預金出納帳の記入問題が出題される。

  1. 残高欄の計算：前残高 ＋ 預入 − 引出 を毎行積み上げる
  2. 小切手番号の記入：引出（振出）行には番号を忘れずに記入
  3. 当座借越の発生確認：残高がマイナスになったらΔ（またはカッコ）表記
  4. 総勘定元帳との整合性：出納帳の預入合計・引出合計・残高は当座預金勘定と一致するはず

注意点として、銀行勘定調整表（未取付小切手・未取立小切手等の調整）は簿記3級の出題範囲外だ。3級では当座預金出納帳の記入と残高計算に集中すれば十分だ。

混同しやすい用語

帳簿対象特徴的な欄
当座預金出納帳当座預金の入出金小切手番号欄あり
現金出納帳現金の入出金小切手番号欄なし
普通預金出納帳普通預金の入出金振込番号等
  • 当座預金出納帳 vs 現金出納帳：記録対象が異なる（当座預金か現金か）
  • 当座預金出納帳 vs 銀行勘定調整表：出納帳は自社側の帳簿記録、銀行勘定調整表は銀行残高との差異調整（3級範囲外）

試験対策・関連リンク

簿記3級 過去問・勉強方法・独学・仕訳を網羅的に対策するなら、当座預金出納帳は「預入で増、引出で減」というシンプルルールと、残高マイナス時のΔ表記をセットで覚えよう。簿記3級 独学では現金出納帳と当座預金出納帳の両方を同じフォーマット感覚で練習し、「何が入出金の理由か」を摘要で表現できるよう練習しよう。簿記3級 過去問では当座借越が絡む問題も出るため、残高がマイナスになったときにΔ表記することも覚えておくと対応できる。
